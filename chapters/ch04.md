# 第4章 一顶帽子的生产之旅:流程与时间

前三章你认识了布料、零件和工艺,这一章把它们串起来:跟着一批面料走进工厂,看它怎么一步步变成装箱待运的帽子。读完这章你会得到两样东西:一是**跟工厂对话的底气**——催货时你知道货卡在哪个环节、该问谁;二是**对"交期"的正确理解**——为什么生产只要15天,工厂却报你35天,哪些天是真需要,哪些天是可以谈的。

## 4.1 总流程图

### 4.1.1 全流程动线

一张订单在车间里的物理路线是固定的:

```
面辅料入库 → 验布 → 裁剪 → 绣花 → 车缝 → 后整 → 包装 → 成品入库 → 出货
```

记住一个反直觉的点:**绣花在车缝之前**。logo是绣在还没缝成帽子的平整裁片上的,不是绣在成品帽上(原因见4.3.1)。新手想象中"帽子做好了再绣个字",恰恰是效果最差的做法。

### 4.1.2 并行与串行:瓶颈在哪

不是所有环节都要排队等。**面料采购和绣花制版可以并行**(料在路上时,制版师已经在打带出样);**裁剪和绣花之间是紧耦合**(裁片出来才能上绣花机);**车缝是整条链的产能瓶颈**——它人最多、工序最碎、最容易堵。所以工厂排产的本质是围着车缝线的档期转:你的单什么时候能做,取决于车缝线什么时候空出来,而不是仓库里有没有布。懂了这一点,你催单时就该问"我的单排在哪条车缝线、几号上线",而不是笼统地问"做到哪了"。

## 4.2 裁剪工序

### 4.2.1 验布:第一道防线

面料进厂先过**验布机**——布卷在灯箱上匀速展开,工人盯着看三样东西:**色差**(同批布不同段颜色不一致)、**破洞/断纱**、**纬斜**(纬线歪斜,布纹不正——用这种布裁的帽片,做出来的帽子会"拧着")。验布是最容易被小厂省掉的环节,省掉的后果要到成品才爆雷,而那时布已经变成了几千顶帽子。

### 4.2.2 松布:让布先"喘口气"

布卷是紧绷着卷起来的,内应力没释放,直接裁会怎样?裁的时候尺寸是对的,做成帽子放两天,布自己回缩,帽子变小一号。所以正规做法是裁前**松布**(把布摊开静置12-24小时,让它回到自然状态);棉布还要考虑第1章说的缩水,讲究的厂会先缩水处理。你验厂时看到裁床边摊着一堆"晾着"的布,那是好信号,不是懒散。

### 4.2.3 排料与唛架:省下来的都是利润

一顶帽子的六片裁片是扇形的,怎么在一幅布上摆放,浪费的边角料差别巨大。把所有裁片在布面上的最优摆放方案画出来,叫**排料**,输出的那张"拼图"叫**唛架**(现在都是电脑软件排)。衡量指标是**用料率**——好的排料能到85%以上,差的只有75%,同一张单面料成本差出10%。第9章说单顶用布0.15-0.18㎡,区间的高低端,差的就是排料水平。

### 4.2.4 裁床:电脑裁与手工裁

布按唛架铺成几十层(**拉布**),然后下刀。**电脑裁床**自动走刀,精度高、层数多;小厂用**手工电剪**,老师傅推着电动裁刀沿线走,精度看手艺。裁片精度直接决定车缝的顺畅度——裁片差一毫米,车缝工就要用手"匀"进去,匀不好就是歪缝。

### 4.2.5 扎号:防色差的最后一道保险

第1章讲过缸差:同色不同缸的布有细微色差。几十层布裁下来,每层可能来自不同布卷——如果第3层的前片配了第17层的后片,一顶帽子上就会出现两种"红"。防法叫**扎号**(打号):裁完后给每一层的每一片贴上层号,车缝时**同号相配**,保证一顶帽子的六片全部来自同一层布。验货时发现帽片之间有色差,几乎可以断定是扎号环节偷懒了——这是个可以精准问责的质量点。

## 4.3 绣花工序

### 4.3.1 为什么绣花排在车缝前

三个原因:**平片好绣**(平整的裁片能绷紧在绣花框上,针脚均匀;缝成立体的帽子后前幅是弧面,绣花质量断崖式下降)、**好定位**(平片上logo位置可以精确画线)、**坏了不心疼**(绣坏一个裁片损失几毛钱布,绣坏一顶成品帽损失十几块全部工序)。

### 4.3.2 上绷与定位

裁片被夹进绣花框(**上绷**),按定位模板对准位置,一框十几片,推进多头绣花机(机器原理见3.1.4)。**绣偏**——logo没绣在前幅正中——多发生在上绷马虎或定位模板磨损时,是绣花车间的头号疵点,验货时拿一摞帽子对齐了看logo高低,一眼能看出来。

### 4.3.3 成品帽绣花:例外情况

有一种专门的**帽绣机**,带弧形绣框,能在缝好的成品帽上绣——什么时候用?**现货帽二次加工**:客户要得急、量又小,直接拿仓库里的空白成品帽绣logo,三五天交货。代价是效果打折(弧面针脚不如平绣均匀、绣花范围受限)。第3章工艺决策里"量小要快→现货帽+成品绣"说的就是这条路——快和好之间的标准取舍,接单时要跟客户讲明白。

### 4.3.4 绣花外发:问清这一条

不是每家帽厂都有绣花车间——不少厂把绣花**外发**给附近专业绣花厂。外发本身不是问题(专业绣花厂设备可能更好),问题在**交期和品控多了一道转手**:旺季绣花厂排队,你的裁片在别人厂里躺一周,你的工厂也只能干等。所以第12章验厂50问里必有一问:"绣花是自有车间还是外发?"自有绣花产能的厂,定制小单的交期弹性大得多。

## 4.4 车缝工序

### 4.4.1 工序分解:一顶帽子缝几步

车缝不是一个人从头缝到尾,而是拆成十来道工序流水作业。以经典6片帽为例:

| 工序 | 做什么 | 用什么机器 |
|---|---|---|
| 拼片 | 六片两两拼成三组,再合成帽身 | 平车(普通缝纫机) |
| 合缝/压线 | 拼缝处压明线加固 | 双针车 |
| 上沿条 | 帽内缝份包边(见2.2.3) | 嵌条机 |
| 锁气眼 | 绣眼锁边(金属鸡眼另用打扣机) | 凤眼机 |
| 做檐 | 檐面布+檐芯组合、车檐面线 | 帽檐机 |
| 上檐 | 帽檐与帽身缝合 | 厚料平车 |
| 上汗带 | 缝入汗带、夹入织唛 | 平车 |
| 上扣 | 装调节扣、后开口收边 | 平车/打扣机 |
| 钉顶扣 | 帽顶装顶扣 | 撞钉机 |

不用背,但要有概念:**帽型越复杂,工序越多,工缴越贵**——第9章说6片比5片贵、夹沿条加钱,现在你知道钱具体加在哪台机器上了。

### 4.4.2 流水线逻辑

一条帽子车缝线通常10-20人,每人固定做一两道工序,半成品沿线传递。流水线的效率取决于**平衡**——最慢的那道工序决定整线速度。这解释了两件事:为什么工厂讨厌小单换款(每换一款,全线重新磨合,头两天效率只有一半);为什么翻单便宜且快(工人手熟了,直接起速)。

### 4.4.3 计件工资与工价表

车缝工人拿**计件工资**:每道工序一个单价,记在**工价表**上——上檐0.35元/顶、拼片0.25元/顶……工人做多少计多少。第9章"车缝工缴¥2.5-4"就是整张工价表的加总。计件制的一个隐藏后果对你很重要:**难做的款没人愿意做**——同样一小时,做简单款挣得多,你的复杂款如果工价没上调,就会被工人挑剩下、排到最后、还做得毛躁。所以听到工厂说"这款要加工缴",先别当成宰你,很可能是真话。

### 4.4.4 产能估算

一条平衡良好的熟练线,普通6片绣花帽日产800-1200顶。由此可以自己验算工厂的话:它说"5000顶一周出货",意味着要么两条线并做,要么你的单独占一条线五天——旺季这两种情况都稀罕,报价爽快交期也爽快的,多半后面要延。

## 4.5 后整工序

### 4.5.1 定型:帽型是"烫"出来的

缝好的帽子其实是软塌无形的。**定型**是把帽子套在加热的头型铝模上,蒸汽加压定几十秒,帽身立体感、帽檐弧度就此固定——你在店里看到的挺括帽型,是这一步给的。软顶dad hat定型轻,结构化棒球帽定型重,水洗做旧款(见3.3.3)则是先洗再定。

### 4.5.2 剪线与修整

流水线上每道工序都会留线头,后整车间的工人逐顶**剪线**、翻查内里。线头是验货时的头号扣分项(第11章疵点图鉴里的常客)——不是致命缺陷,但一顶帽子翻开三根线头,客户对整批货的信任就没了。它也是判断工厂管理水平最简单的探针:连线头都懒得剪的厂,别的更别指望。

### 4.5.3 整烫与除污

最后过一遍蒸汽整烫、检查污渍(车缝机油印是常见污染源)、能除的除掉,除不掉的挑出来算损耗——第9章损耗率2-3%,一大半就耗在裁剪疵片和这里的污损上。

## 4.6 包装工序

### 4.6.1 单塑袋

每顶帽子独立装一个透明塑料袋(**polybag**),防潮防污。出口件的塑袋上通常要印**窒息警告语**(suffocation warning,欧美市场对塑料袋的强制要求)——小细节,但清关和客户验货都会看。

### 4.6.2 装箱:嵌套的学问

帽子是"抛货"(第17章会算这笔账),装箱方式直接决定运费。标准做法是**嵌套**:帽子一顶套一顶摞成柱,再排进箱——比单顶平放省一半体积。但嵌套过深会压塌帽型、压弯帽檐,行业默认6-12顶一摞。一个标准外箱(60×40×40cm级别)装100-150顶。报运费前先问工厂"装箱数是多少、外箱尺寸多少",这两个数是第19章算到岸成本的必备输入。

### 4.6.3 外箱与箱唛

外箱用五层瓦楞纸箱(海运颠簸,三层的到港就烂)。箱外印的信息叫**箱唛**(shipping mark):收货人简称、目的港、箱号(如 3/28,第3箱共28箱)、数量、毛净重、体积。箱唛不是形式主义——目的港仓库靠它分货,报关单证上的件数毛重要跟它对得上,对不上就是海关质疑的由头(第16章装箱单会再遇到它)。

### 4.6.4 电商包装的区别

传统外贸包装到外箱为止;发亚马逊FBA的货还要贴**产品条码标**(每顶帽子的塑袋上贴FNSKU码)、外箱贴箱标,规格错了入仓被拒。做电商路线(第22章)的读者,下单时就要把贴标要求写进包装规格,让工厂代贴——自己到货再贴一遍是双倍人工。

## 4.7 时间账:从生产周期到交期

### 4.7.1 各工序标准耗时

以一张5000顶的常规绣花帽订单为例,纯生产环节:

| 环节 | 耗时 |
|---|---|
| 验布+松布 | 1-2天 |
| 裁剪 | 1-2天 |
| 绣花 | 2-4天(视针数与机台数) |
| 车缝 | 5-7天 |
| 后整+包装 | 2-3天 |
| **生产合计** | **约12-18天** |

### 4.7.2 交期构成:另一半时间去哪了

但工厂报给你的交期是30-40天,多出来的部分长这样:

```
签单收定金 → 产前样制作与确认(4-7天,含快递和你的确认速度)
          → 面辅料采购到位(5-10天,定制色面料更久——见1.5.2)
          → 排产等待(0-10天,旺季车缝线排队)
          → [生产 12-18天]
          → 验货+订舱等船期(3-7天)
```

看懂这张表,三个实用结论:一,**你自己就是交期的一部分**——产前样照片发你,你拖三天确认,交期就长三天;二,**备料和排产是弹性最大的段**,跟单员关系好(见8.7.1)、辅料用现货、避开旺季,能各省几天;三,**"生产周期15天"和"交货期35天"都是真话**,工厂没骗你,只是说的不是同一件事——签PI时写清楚交期从哪天起算(常规写法:从收到定金和确认产前样之日起算),省掉日后一半的扯皮。

### 4.7.3 排产与插单

工厂的生产日历按周排满,你的单进来是**排队**,不是马上做。**插单**——把你的单塞到队伍前面——是真实存在的操作,但它动的是别人的档期,只有两种人能要到:大客户,和有人情的人(见8.7.3)。反过来你也要有心理准备:你是小单时,被别人插队是常态,交期buffer留2周不是保守,是经验。
