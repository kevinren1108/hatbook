# 第7章 钱的地图:价值链与利润分布

**主线推进** —— 傍晚,绣花外发厂的面包车把最后两筐绣好的前幅送回车间,明天一早,车缝线就要全面吃上你的单。你回到镇上的快捷酒店,把这一个多月攒下来的数字第一次全部摊开在桌上:Mike 的四千九百五十加元(定金三成已到账)、工厂的八千七百五十块货款、货代报的海派运价、制版费、寄样快递单,还有一个你只听说过、没见过的词——退税。你忽然意识到一件事:从接单到现在,你核过面料、验过克重、算过针数,却从来没有把这条链上"谁赚走了什么"从头到尾算清楚过。第0章你见过那两个画面——温哥华货架上一顶标价29.99美元的棒球帽,和它离开中国工厂时十几块人民币的出厂价——当时那只是别人的故事;今晚不一样了,**你自己就站在这条链上**,却还说不清自己赚的是哪一段的钱、凭什么赚、能赚多久。这两天你看完了行业的格局(第5章)和产业带的地形(第6章),今晚把最后一张图补上:钱的地图。台灯拧亮,你翻开笔记本新的一页,在页首写下一行字:这一单,每一手,谁赚多少。

## 7.1 链条解剖

### 7.1.1 从¥15出厂价到$29.99零售价:每一手加价表

先把第0章那顶帽子请回桌面。一顶普通的绣花棒球帽,离开胶州这样的工厂时出厂价约¥15,按全书汇率口径(见0.3)折合2.11美元;几个月后,它躺在北美一家零售店的货架上,吊牌29.99美元——十四倍多。新手看到这个倍数,第一反应几乎都一样:中间的人在暴利。你今晚要做的第一件事,就是把这十四倍逐手拆开,拆完你会得出一个反直觉的结论:**这条链上没有谁在暴利,每一手的加价里,大头是成本和风险,利润只是尾巴。**这条从工厂到消费者、每一手都加一道价的链,行内借管理学的词叫**价值链**——听着抽象,拆开就是一张表:

| 环节 | 拿货价 | 卖出价 | 加价幅度 | 这一手承担什么 |
|---|---|---|---|---|
| 工厂 | 材料+工缴约¥13.8 | 出厂¥15(≈$2.11) | 约8个点 | 厂房设备、几百工人的工资、垫料垫工、质量返工 |
| 贸易商/出口商 | ¥15 | FOB约$2.50(≈¥17.8) | 约15个点 | 跟单验货、单证报关、垫定金、收汇汇率、客户跑单 |
| 进口商/品牌方 | 到岸约$3.30 | 批发$13 | 约4倍 | 海运关税、整柜库存压半年、款式开发、品牌营销、滞销 |
| 零售商 | $13 | $29.99 | 约2.3倍 | 房租人力、试戴损耗、季末清仓、退货 |

逐手念给你听。第一手,工厂:¥15的出厂价里,材料辅料工缴占掉近¥14,毛利一两块钱——具体怎么拆,7.2.1整节算给你。第二手,贸易商按¥15拿货,以**FOB价**卖给海外买家——FOB即离岸价,货送到中国港口装上船为止的价格,责任费用的完整分界到13.3.1精讲,这里先当"卖给外国客户的出口价"理解——报$2.50,折¥17.8,毛利率约15个点,赚的是语言、渠道和担责的钱(7.2.2展开)。第三手,进口商或品牌方:FOB价之外,还要自己掏海运费(整柜摊到每顶不过一两毛美元,规模效应见17.1)、关税税费、目的国内陆运仓储,货到自己仓库的完整成本约$3.30——这个"货送到手上一共花了多少"的数,行话叫**landed cost(到岸成本)**,全书最重要的一个数,第19章整章教你算,这里先记住名字。然后他以$13的批发价卖给零售渠道,加价约四倍——最凶的一手,但注意他扛的东西:一柜货几万顶压在仓库里周转半年,款式开发和品牌广告的钱全在这一手里烧,一个滞销季就能把几年利润吐回去。第四手,零售商$13进、$29.99卖,加价2.3倍,养的是房租、店员和卖不掉的那三成货(7.2.3算细账)。

看懂这张表,你就拿到了本节最要紧的那句话:**加价不等于利润。**每一手的加价=这一手的经营成本+这一手的风险准备金+最后剩下的利润。四倍加价的品牌方,净利率常常只有个位数到10个点;2.3倍加价的零售店,年底一算净剩的也是个位数。链条上每个位置的"点数"和"倍率"长得完全不一样,但净利差距远没有表面那么悬殊——因为**加价高的位置,一定是成本重、风险大、离消费者近的位置**;市场不给白拿的倍率。

一段对话帮你把这个认知焊死。做外贸的社群里,隔三差五就有人发这种帖子:"兄弟们,帽子出厂两美金,亚马逊上卖三十,十五倍!这还不冲?"三个月前的你可能真会心动;今晚的你可以一句话拆掉它:"你冲进去之后,占的是链条上哪一手?品牌方那一手吗——那你准备好压多少库存、每月烧多少广告?零售那一手吗——你的流量从哪来?"十五倍是**整条链所有人的成本加起来**的倍数,不是留给任何一个新进场者的空间;你能赚的,永远只是你实际顶替的那一手的钱。这也是"钱的地图"的用法:**看到任何一个诱人的价差,先问它横跨了几手,再问你有能力顶替其中哪一手。**

本节动作:把上面那张表抄成你的分析模板(栏目:环节/拿货价/卖出价/加价幅度/承担的成本与风险),以后凡有人向你描述一个"暴利生意",先逼自己把这张表填满再动心——填不满,说明你连钱从哪流过都没看清,更别提伸手去截。

### 7.1.2 加价倍率与毛利率:两个常混淆的概念

上一节的表里,工厂那行写"8个点",零售那行写"2.3倍"——你有没有停下来问一句:"点"和"倍",到底是不是一套算法?这一节把它掰开,因为**这是新手报价时最容易亏钱、也最容易被绕晕的一对概念**,不夸张地说,分不清它们的人不该报价。

两个定义,现场钉死。**加价倍率**:卖价除以成本,答案是"几倍"——成本¥20卖¥30,倍率1.5倍;与它同源的说法叫加价率,(卖价−成本)÷**成本**,同一个例子是50%。**毛利率**:(卖价−成本)÷**卖价**——注意分母换成了卖价,同一个例子,(30−20)÷30≈33%。同样一笔买卖,"加价50%"和"毛利33%"说的是一回事,数字却差出十七个点——**差别全在分母:加价率除以成本,毛利率除以卖价。**再给一对换算公式,值得抄在手机备忘录里:毛利率=1−1÷倍率;倍率=1÷(1−毛利率)。代两个数你就有感觉了:2倍加价=毛利率50%,不是100%;想要毛利率50%,要加价2倍,不是1.5倍。顺带把第三个词也认了:毛利之外再扣掉房租、工资、广告这些经营费用,剩下的才叫净利,净利÷卖价即净利率——本章说"工厂5-15个点""贸易商10-20个点",说的都是毛利率口径;净利还要再薄一层。

为什么行业里两套话并存?习惯使然:**零售和品牌端开口是毛利率**("我们做户外渠道要五十个点"),**工厂端开口常是加价口径**("这单我就加你五个点");同一个"点"字,分母不同。所以给你一条实战纪律:**凡是听到"点",先问分母**——"您说的四十个点,是按卖价算还是按成本算?"一句话,土,但它救过很多单的利润。

看一场真实质感的翻车,数字都给你留着。一位刚起步的同行接了美国客户1000顶渔夫帽,含运含税到门,他把成本算得很扎实:每顶合计$4.10。客户邮件里写"我们这边渠道要留40个点",他心想:那我自己也留40个点吧——**于是按成本乘以1.4报价:$5.74。**错在哪?"留40个点"是毛利率,正确算法是成本除以(1−40%):4.10÷0.6=**$6.83**。一乘一除,每顶差$1.09,1000顶,报价那一秒就把一千多美金让出去了。故事还没完:谈判中他又让了5%,成交$5.45,此时真实毛利率只剩(5.45−4.10)÷5.45≈25%;收款走PayPal,手续费吃掉营收的4.4%;结汇再损1个点;后来补寄15顶瑕疵货,快递$180——期末一算,到手$875左右,合**16个点**。他从头到尾以为自己"留了40个点",实际连一半都没拿到;要是中间再出一次像样的事故,这单就是白干。病根只有一个:**他用加价的算法,去兑现毛利率的承诺。**

回到你的主线核对一下姿势。你给 Mike 报的是9.9加元/顶到门(这单的完整分账在7.3.2摊开),假如当初你的目标是"到手一半",正确的检查方式是:毛利率=(卖价−成本)÷卖价,而不是看"我在成本上乘了几"。以后每次报价,流程固定成一句话:**先定目标毛利率,报价=成本÷(1−目标毛利率),报出去之前再用毛利率公式倒验一遍。**乘法留给别人犯错用。

本节动作:在手机备忘录建一条置顶,就三行——①报价=成本÷(1−目标毛利率);②毛利率=1−1÷倍率;③听到"点"先问分母。然后做一道自测:成本¥22,目标毛利率45%,该报多少?(答案:22÷0.55=¥40,而不是22×1.45=¥31.9——两个答案差出的¥8.1,就是这一节的全部价值。)

## 7.2 各环节真实毛利

### 7.2.1 工厂:5-15个点,靠量、翻单和退税活着

白天你在车间外的走廊上看过一块白板:八条车缝线,每条线后面写着当天的目标产量和实际产量,差几十顶的那条线用红笔圈着。晚上回来拆账你才真正看懂那块白板的意思——**在5-15个点的毛利率里,工厂每天追的那几十顶,就是利润本身。**空口说薄没有感觉,拿你自己的帽子开刀:R&B 主款出厂价¥17.5,把它拆到底:

| 成本项 | 金额(¥/顶) | 口径出处 |
|---|---|---|
| 面料(磨毛斜纹,含裁耗) | 1.5 | 见1.5.1 |
| 里衬、檐芯等结构料 | 1.0 | 见2.1.1 |
| 辅料(金属滑扣+收尾环、气眼、汗带、织唛洗水标、包装袋箱) | 2.5 | 见2.3/2.4 |
| 绣花(8800针×¥0.45/千针,外发) | 4.0 | 见3.1.5 |
| 裁剪与车缝工缴 | 3.5 | 见4.4.3 |
| 后整、定型、包装工缴 | 0.9 | 见4.5/4.6 |
| 水电房租、设备折旧、管理人员摊销 | 1.8 | — |
| 损耗(按2-3%计) | 0.4 | 见4.1 |
| **成本合计** | **15.6** | |
| **工厂毛利** | **1.9(约11个点)** | |

一顶¥17.5的帽子,工厂赚¥1.9——这还是小单的价:500顶要单独排产、单独调线,点数本来就给得靠上;同样这顶帽子如果是十万顶的长单,出厂价会被砍到¥15.5-16,点数掉到5-8个。为什么工厂没有还手之力?第5章你刚看过答案:全球前十厂商份额不足15%,高度分散意味着客户永远找得到第二家报价(见5.2.2),而工厂的成本结构里,材料辅料工缴全是市场价,谁也藏不住——**一个人人都会算的成本表,撑不起高毛利。**

那工厂靠什么活?三根柱子。第一根,**量**:带你算年账——八条线、日产八千顶、一个月开二十五天、一年有效生产算十一个月,约二百二十万顶;单顶净赚¥0.8-1.5,一年就是两三百万——前提是全年吃饱,淡季线一空,固定成本照烧,这个数直接打八折。所以工厂最怕的不是价低,是没单:**宁可微利接单养线,不能停线等价**,你以后听到工厂淡季报出"不像话"的低价,背后是这笔账。第二根,**翻单**:第一单要打样、制版、调机、工人学新款,换款损耗全在里面(见4.4.2);翻单时这些全免,工人手熟效率再涨两三成——同一个价,翻单能多挤出两三个点的利润。这就是为什么工厂对翻单客户又爱又让着:**你嘴里的"老客户",在工厂的账本上是一条毛利率更高的生产线。**第三根,**退税**:帽子出口退税约13%,机制到18.3细讲,这里只把量级给你——落到这顶¥17.5的帽子上,退税带来的现金回流约¥0.8-1.2,**对一个毛利只有¥1.9的工厂,这笔钱接近毛利的一半**。所以有的工厂敢把报价贴着成本报,把退税当利润(见9.7.3)——你在1688上见过¥13.9的"同款",现在你有了两把解释的刀:要么在成本表里减了配(第9章教你逐行抓),要么就是把退税折进价里的走量打法。

对话样本,是你砍价前必须先听懂的一句行话。你试探性地问过一句"量再大点,价格还有没有空间",对方答:"实话说,这个价我就赚个加工费,再让就要在料上想办法了。"——前半句是真话:11个点里,材料辅料是市场价、绣花是外发价,能"让"的只有工缴和管理摊销那五个来点;后半句是警告也是实情:**砍掉的价一定会从成本表里最软的那格找回来**(降克重、换辅料档次,手法见9.2.2、9.3.2)。所以给你一个谈判阈值,先立在这里、第9章还会用到:**对工厂的还价空间,常规就在3-5个点以内;有人爽快答应你砍10个点,不是你赢了,是配置输了。**

本节动作:把上面那张拆解表存档,以后拿到任何一张帽子报价,先自己按这个框架拆一遍BOM(材料+辅料+工艺+工缴+摊销+损耗),再对照工厂报价——报价低于你拆出来的成本合计,不要窃喜,逐格去找哪一格被动了手脚;报价高出成本合计五个点以上,那多出的部分才是真正可谈的(见9.6.2)。

### 7.2.2 贸易商:信息差的10-20个点,与被两头挤的宿命

晚饭你是在镇上一家小饭馆解决的。邻桌两个人的对话你越听越入神——其中一位做了十年帽子外贸,正跟同伴倒苦水:"昨天美国客户发我一张1688截图,同款帽子,问我为什么贵15%。我能怎么说?我说你按截图买一次试试——他还真去买了,你猜怎么着,今天又回来了,说收到的样品克重不对、没人理他。"同伴笑,他不笑:"这次他回来了。下次呢?"

这段对话就是贸易商这一手的全部处境。先说他的10-20个点从哪来。教科书会说"信息差":他知道哪家厂做金属扣款最稳、哪家绣花厂旺季不掉链子、哪个价是实价哪个价是钓鱼价——这些信息客户没有,愿意付钱买。但信息差只是入场券,真正支撑点数的是三样更重的东西。**整合**:海外客户要的常常不是"一款帽子",是帽子加T恤加袜子三个品类、五个款式各几百件,背后是三四家工厂——每家工厂都嫌单小,贸易商把它们拼成自己的采购量,拿着几家的货拼一个柜(拼箱的账见17.2),客户面对的始终只有一个人。**担责**:货出了问题,工厂的责任边界是"返工"(见11.6),而贸易商对客户签的是整单交付——赔偿、补货、空运追时效,先扛下来的是他;客户多付的点数里,有一部分是保险费。**服务**:时差里秒回的邮件、打样三轮的来回盯、验货、单证、物流,全是工厂不愿干或干不好的活。**贸易商真正卖的不是帽子,是"确定性"**——这句话你记住,因为它马上也是你的商业模式。

再说"被两头挤"。第一头,客户比价:阿里国际站和1688把中国工厂摆到了全世界买家的浏览器里(平台的账见21.1),纯粹的价格信息差正在肉眼可见地消失——开头那位同行的15%,十年前是30%。第二头,工厂直客化:工厂自己开国际站账号、自己拍短视频接海外单(这股潮流第23章你会站到它有利的一面),等于供应商亲自下场做你的竞争者。两头一挤,纯搬运型的贸易商——只转发报价、赚差价、不提供任何增量价值的那种——点数一路被压向个位数,直到无利可图。这不是预测,是正在发生的事。

一场事故,把"挤"的第三种形态也给你看了:**被绕过**。那位同行讲了他自己交学费的一单:早年他有个合作三年的美国客户,每年翻两次单。有一年出货,工厂按惯例刷箱唛(见4.6.3),箱唛上印着客户公司名和目的港;第二年广交会,那家工厂的业务员在展位上直接把名片递到了这位客户手里,报价低8%。第三年,客户的单没有再来。"怪工厂吗?"他自己回答自己,"怪我。三年里我除了转单,没给客户干过一件工厂干不了的事——人家绕过我,一点损失都没有。"从那以后他的规矩改了:箱唛用自己公司的代码、单证信息脱敏是基本功(操作细节见16章),但更根本的是**每一单都要留下工厂替代不了的痕迹**:替客户做款式建议、整合多厂供货、扛住一次索赔——让"绕过你"这件事变得有成本。

你现在就是一个贸易商——R&B 这单里,你既不拥有工厂也不拥有品牌,你站的正是中间这一手。所以这一节的结论请对号入座:**信息差会持续贬值,整合、担责、服务不会。**靠前者只能赚到行业的过去,靠后三样才能赚到它的未来。

本节动作:从这一单开始养成一个月度自问,写进你的复盘模板:"这个客户的最近一单里,我除了转发报价和转账,还干了哪三件事?"——三件都答得上来(比如:改过他的方案、拦过一次质量问题、垫过一次时效),这个客户就还是你的;答不上来,别等箱唛泄密,他已经在离开的路上了。

### 7.2.3 批发与零售/DTC:2-4倍加价背后的库存与流量成本

正拆着账,Mike 的邮件进来了,像是掐着点要给你这一节当教材。译过来是:"生产顺利吗?对了,帽子到了我们打算吧台卖30一顶,周年活动那天买两杯酒送一顶。上次做T恤,进价9块卖25,我一直以为自己挺黑的——直到年底盘库,发现赚的钱全压在两箱没人要的XL码里。Mike"

先接他前半句:你的到门价9.9加元,他卖30,正好3倍——落在零售2-4倍加价的标准区间里。北美零售有个老行话叫**keystone定价**:进价翻倍挂牌,毛利率50%,是实体零售的传统底线;帽子这类小件配饰,常规做到2.5-4倍。为什么"底线"就要翻倍起?把一家零售店的毛利率拆开你就服了:以7.1.1那顶$13进、$29.99卖的帽子为例,毛利率57%,听着肥,往下扣——房租摊掉营收的15-20个点,店员工资10-15个点,刷卡手续费和损耗2-3个点;最狠的一刀是 Mike 邮件后半句说的那个东西:**滞销**。零售业用**售罄率(sell-through)**衡量它:一批货按原价卖出去的比例。带你算一批:100顶按$29.99上架,原价卖掉70顶、季末五折清20顶、最后10顶按清仓价甩——实际收入约$2,450,只有理论营收的八成出头;那"消失的两成",分摊到每一顶卖出去的帽子上,又是十来个点的成本。四刀扣完,一家经营正常的帽子零售店,净利率剩个位数——**2-4倍加价养的不是老板的口袋,是房租、人力和卖不掉的那三成货。**批发商的账同理,只是把"房租+滞销"换成"仓库+压款":他一次吃进几千上万顶,给下游零售店铺账期,赚的那一倍多加价里,一大块是资金和库存的利息。

再讲这个词:**DTC(direct-to-consumer,直面消费者)**——品牌不经过批发零售,自己开网店直接卖给消费者。听起来是把中间两手的钱全省下来了,对吧?新手都这么想,直到认识另一个词:**获客成本(CAC)**,平均烧多少广告费才换来一个下单的客户。DTC的账长这样:$29.99的帽子,货的到岸成本$5,投放广告换一个订单常见要$10-14,发到消费者手里的尾程运费加包装$6-8,支付手续费、退换货摊销再去$3——**剩下的和实体零售的净利,惊人地接近**。传统零售把15-20个点交给房东,DTC把30个点以上交给广告平台——**广告费就是新房租**,而且这个房东天天涨价。亚马逊路线也一样,只是房东换成平台佣金和FBA费用,那笔账22.1.2会一分一分算给你看。一句话立住本节的判断:**流量不是免费的,谁离消费者近,谁就在给流量付费;2-4倍加价是这笔费用的对价,不是暴利的证据。**

那 Mike 为什么是例外?看他的结构:酒厂的吧台就是现成的货架——房租早被卖酒摊掉了,来买帽子的人本来就是进店喝酒的常客——**获客成本是零**。9.9进、30卖,他这一手是整条链上最肥的,肥得干干净净。这里藏着一个对你未来获客极其重要的洞察(第五部会反复用到):**自带线下流量的小商家——酒厂、咖啡馆、健身房、球队——是定制帽生意里双赢最大的客户**,因为你帮他把"最肥的一手"装进了他自己的口袋;他赚得越明白,翻单越痛快。至于他那两箱XL的教训,替他记着:做帽子比做T恤幸运,均码调节扣(见2.4)天然免掉了码数滞销——这句话,下次给服装类客户提案时值一分信任。

本节动作:把"帮客户算他那一手"做成你方案的固定页。给任何终端客户报价时,附一行字,套用今天这个模板:"按您零售__元计,单顶毛利__元、毛利率__%,售出__顶即覆盖整批采购成本。"(对 Mike:卖30,每顶毛利20出头,卖165顶就回本500顶的全部货款。)你不再是报一个成本,而是递给他一门生意——这一页纸的说服力,超过降价一加元。

## 7.3 三个利润档位

### 7.3.1 走量代工:赚加工费的数学与天花板

回酒店的路上你经过镇子北头,那家全镇最大的帽厂灯火通明——十几条线在赶夜班。白天听厂区的人说起过它:给两个美国大牌做代工,一年出货五百万顶。你顺嘴问了句"那得赚多少",对方笑笑:"算下来,未必比镇上做跨境电商的两口子多。"当时你以为是酸话,现在你会算了——这一节,把三个利润档位的第一档拆给你:**走量代工**,也就是行业地图里的OEM模式(定义与三模式对比见5.3.1),按客户的设计和订单生产,赚加工费。

它的数学冷得像一台计价器:**年利润=产能×开机率×单顶净利**,三个变量,一个都不浪漫。拿你熟悉的这家八条线中型厂代入:产能一年约二百二十万顶;开机率按吃得比较饱算九成;单顶净利含退税¥0.8-1.5——乘出来,一年一百六到三百万。这就是答案的全部,而且三个变量各有各的硬:单顶净利被7.2.1拆过,5-15个点的毛利扣完费用就剩这几毛一块,提升空间以"分"计;开机率靠淡季接微利单硬填;于是**想多赚,只剩"产能"一个变量可动**——天花板就露出来了:加产能=盖厂房、上设备、招几百工人,几百万资本开支砸下去,新增的线必须立刻有大单来填,否则开机率崩、全盘账崩;而填得满八条、十六条线的单,只能来自大客户,大客户的采购逻辑(见5.5.1)是每年招标、逐年压点——五百万顶那家厂,行里传闻它给核心客户的点数八年间从12个被谈到6个。**产能翻倍,议价权减半,这是走量代工的宿命循环:规模是它的护城河,也是它的人质。**规模化代工能不能破这个局、天花板之上还有什么,尾声"代工天花板的数学"会给出全书最后的答案,这里按下。

那这档钱谁该赚?看门槛就知道:它筛掉的恰恰是"新人"两个字——你没有产能,没有压给设备的资本,更没有喂饱一条线的订单来源。0.2的画像一(家里有厂的)是唯一的例外:厂已经在了,固定成本已经沉了,你要做的不是进入这一档,而是**站在这一档的肩膀上往外长**——把家里的产能当成你的底价和交期优势,自己去做海外前端赚贸易和服务的钱,这条"你管嘴和手、工厂管货"的路线,27.1整节铺开。而对画像二、画像三,这一档的正确用法是**看懂它、利用它,不进入它**:看懂工厂靠量活着,你才明白淡季议价、翻单让利这些机会窗口在哪(见24.1.2);看懂单顶净利以毛计,你才不会提出"再砍两块钱"这种等于让对方亏本的要求。

一段对话,把这一档的体感钉死。饭馆那位老外贸提过他早年的东家——一家做到过千万顶的大厂老板的原话:"我这厂子,说白了是给银行和工人打工:设备贷款一年利息七十万,工资一个月发出去两百多万,年底剩给自己的,好年景三四百万,差年景倒贴。隔壁我小舅子,俩人一间办公室做定制单,一年挣得不比我少,气人不气人?"——这段牢骚里没有一个字是假的,它就是**量的档位**的完整画像:营收巨大、现金流巨大、责任巨大,利润率纤细如发。你听懂它,就不会再迷信"有厂才是做实业""量大才是生意"。

本节动作:给自己立一条档位判断规则,写进笔记本:**如果一门生意的赚钱公式里,"量"是唯一能动的变量,它就是代工档——没有产能和资本的人不要进,已经在里面的人(画像一)要往链条两端长。**下一节,看你现在正站着的那一档。

### 7.3.2 定制服务:赚服务费与信息差,新人的主战场

现在,把你自己填进表里。台灯下,你在笔记本上画出这一单的完整分账——R&B,500顶,你报给 Mike 的价:9.9加元/顶,含绣花、含头程物流、含税到门(报价时 Mike 的预算是12以内,你留足了竞争力也留足了自己):

| 项目 | 金额(¥) | 折每顶(¥) |
|---|---|---|
| 收入:500顶×9.9加元=4,950加元 | 25,740 | 51.5 |
| 工厂货款(出厂价¥17.5) | 8,750 | 17.5 |
| 绣花制版费(首单,见3.1.5) | 200 | 0.4 |
| 打样与两轮国际寄样快递 | 700 | 1.4 |
| 成品轻酵素洗(洗水厂外发,见3.3.3) | 500 | 1.0 |
| 海派专线,双清包税到门(关税税费打包在运价内,见17.4) | 1,400 | 2.8 |
| 收款与换汇手续费(约1.5%) | 400 | 0.8 |
| **成本合计** | **11,950** | **23.9** |
| **毛利** | **13,790** | **27.6** |

毛利率约54%。你盯着这个数看了很久——它高得让你不安:第0章明明说,规规矩矩做贸易,这种单毛利常常就一两千块;7.2.2的贸易商也就10-20个点。凭什么你有54?**把两种卖法并排放,答案自己会站出来。**卖法一,纯贸易:你把这500顶按FOB价$2.45加15个点卖给一家加拿大促销品经销商(这类买家见5.5.2),毛利约一千九人民币——正是第0章那句话的口径,你赚的是贸易商那一手。卖法二,就是你现在做的:客户是终端的 Mike,贸易商、进口商、本地经销商这三手中间全没有——**链条被你压短了,被省掉的每一手的加价,合并成了你的54%**。这就是**定制服务**这一档的本质:面向终端客户,把"贸易+进口+分销"几手的活一个人干完,把几手的钱一个人收走。

但54%不是白给的,把你实际干的活列出来,你就知道这笔钱的名目——它分两半。一半叫**服务费**:你把"摸起来厚实、戴旧了好看"翻译成了21支磨毛斜纹240克(第1章整章就是这笔钱的来历);你盯了打样、验了克重、确认了色样;你把工厂、绣花外发厂、货代整合成 Mike 眼里的"一个供应商";出任何问题,Mike 只找你——翻译、整合、担责,7.2.2里贸易商赖以生存的三样,你一样没少干。另一半叫**信息差**:Mike 不知道¥17.5的出厂价,也不需要知道;他知道的是本地礼品公司同规格报价14加元起、交期还比你长——**你的9.9对他是实惠,对你是厚利,信息差的钱赚得堂堂正正,前提是货真价实。**再把丑话的另一面说全:这54%是毛利率,不是你的时薪。往下扣:两趟中国的机票住宿几千块;从市集到交货近四个月的时间;还没走完的路上仍埋着风险(这一单后面真出了几次事,第26章的损益表会把"预算与实际"摆在一起对账)。第一单折算下来,你赚的是**一份认真工作的钱,不是一夜暴富的钱**——但请注意方向:这份钱,量级上已经是纯贸易卖法的七倍。

这一档为什么是**新人的主战场**?拿三档位的门槛互相一照就明白:走量代工要产能和资本,你没有;自主品牌要库存资金和流量能力(下一节算给你看它多烧钱),你也没有;而定制服务的门槛清单是——懂行话、会流程、肯服务、找得到终端客户。前三样,这本书正在一章一章帮你装进口袋;第四样是真门槛:**你的天花板不在利润率,在客户数。**算一笔封顶账:一人操盘,一年认真服务二十个 Mike 量级的客户(首单加翻单三十来单),单均毛利万元上下,年毛利二三十万——想再往上,要么把获客做成系统(整个第五部讲的就是它),要么把流程做成产品让单均耗时下降(见22.4.2),要么升档去背品牌的风险。而此刻最该看清的是:**这一单里最难复制的不是任何环节,是"你在市集上遇到了 Mike"**——运气给了你第一个客户,第五部教你把运气换成管道。

本节动作:把你为这单干过的所有活,按"翻译/整合/担责"三栏列成清单存档。它有两个用途:其一,下次终端客户问"你比工厂网店贵三成,凭什么",你不用辩解,把清单递过去——工厂卖他的是一顶帽子,你卖他的是这顶帽子按时、绣对、完好地出现在他门口;其二,这张清单就是你的报价底气——**服务费的定价权,来自你能说清自己提供了什么服务。**

### 7.3.3 自主品牌:赚溢价,也背库存与营销风险

睡前刷朋友圈,你看到一位同行发的九宫格:自建的小仓库,货架上码着整整齐齐的帽盒,配文"XX品牌首批到仓,3000顶,梦想开箱"。评论区一片恭喜。你顺手点进他的主页往前翻了翻——八个月过去,最近一条动态是:"清仓,全场2.9折,兄弟们帮帮忙。"

这就是第三档:**自主品牌**——自己设计、自己下单、贴自己的商标、直接卖给消费者,赚7.1.1那张表里加价最凶的一手:品牌溢价。先把溢价说公道:它是真的。一顶到岸成本$4的帽子,贴上有认知度的牌子卖$29.99,毛利率纸面80%以上;消费者付的不是布和线的钱,是设计、审美、身份认同——第5章你见过把配件都做成品牌的Yupoong(见5.4.1),溢价是这个行业里唯一能突破"点数"逻辑的钱。但注意语序:**是"品牌"产生溢价,不是"贴牌"产生溢价。**你注册一个商标印上去,市场不欠你一分钱认知——没有认知的"品牌",本质上是在做零售,而且是没有流量的零售。品牌这扇窄门有多窄、值不值得挤,尾声会郑重地谈;这一节先把新人最容易踩碎的两块地板踩给你看。

第一块地板:**库存**。品牌要有款式和颜色的矩阵才像个品牌,而工厂的起订量(见1.5.2的逻辑,成帽同理)决定你每个款色都要吃进几百顶——朋友圈那位同行的账你现在会算了:3款×2色×每色500顶=3000顶,到岸成本按$4.2算,**¥9万现金变成货,趴在货架上**。然后残酷的统计规律登场:多款并推,几乎必然有爆有死。他后来在群里复盘过:A款月销三百多顶撑住了,B款月销四十,C款月销十几;八个月下来,A款赚的钱,约等于B、C两款降价清仓亏掉的钱加上仓储费——**忙一年,账面打平,现金还少了两万,货架上还剩六百顶"资产"。**这就是库存的真面目:它不只是压钱,它是把你"猜错款"的每一次错误都变成真金白银的亏损;而选款,恰恰是新人最没有数据支撑的环节——这也是为什么27.3给画像三的路线叫"先C后B":先用零售现货试出什么卖得动,再谈自己的款。

第二块地板:**营销**。7.2.3的公式在品牌档全额生效,而且更重:新品牌没有自然流量,每一单都要用广告买,获客成本$10-15起步;更要命的是广告是"竞价的房租"——你出价的对手是预算百倍于你的大牌。把两块地板叠起来,得到品牌档的现金流画像:**先付九万买库存,再按月付广告费买流量,收入按天滴灌回来,任何一环断掉,压着的都是你自己的钱。**对比一下你现在的定制服务档:Mike 的三成定金先到账,再付工厂三成定金——客户的钱盖住工厂的钱(这套现金流设计见14.5.1),你全程几乎不垫资。两档生意对现金的胃口,差着一个数量级。

那品牌档留给谁?三个条件,缺一别进:**已验证的款**(有零售数据证明它卖得动,不是"我觉得好看");**亏得起十二个月的钱**(库存+广告至少预算十来万,且做好它归零的心理建设);**流量能力**(会投放,或者有内容获客的手艺——第23章那条路,是小玩家唯一付得起的流量)。而对今晚的你,正确的姿势写一行就够:**用第二档养第三档**——先赚定制服务确定性的钱,攒客户、攒现金、攒对"什么款卖得动"的手感;哪天你的定制客户里有十个 Mike 都在替你验证同一种审美,品牌的第一款,才有了不靠猜的出生证。

本节动作:给品牌冲动上一道闸,把三个条件抄成检查清单钉在笔记本里——已验证的款?亏得起十二个月的资金?自己的流量来源?**三问有一问答"没有",就把品牌计划锁回抽屉,回去多接两个定制单。**冲动最贵的形态,就是3000顶带着自己logo的库存。

## 7.4 定位练习:三个问题决定你赚哪段钱

笔记本翻到最后一页,今晚的地图差一个坐标:你。链条拆完了(7.1),每一手的真实毛利见过了(7.2),三个档位的门槛和天花板也都亮过底牌了(7.3)——现在轮到把"你"放到图上去。别小看这一步:**这个行业里大多数第一年就阵亡的人,死因不是不勤奋,是站错了格子**——没厂没钱的人冲去铺库存做品牌,手握产能的人守着6个点的代工单眼看利润被逐年砍薄。定位不对,越努力亏得越快。三个问题,一支笔,现在就答。

**第一问,资源:你身后有没有一间"自己人"的工厂?**这是三问里最硬的一问,答案没法努力出来。所谓"自己人",标准很具体:能给你接近底价的报价、旺季肯为你插单排期(见4.7.3)、小单不嫌弃、出了问题一起扛——通常只有直系亲友的厂或你自己干过多年的老东家做得到。答"有",你就是0.2的画像一:代工档的成本优势天生长在你身上,你的正解不是留在厂里,而是做那个往外长的前端——用家里的产能做底牌,去赚定制服务和贸易的钱,路线图在27.1,同时提前读一遍28章那个亲友反目的案例,把分利和责任在第一单之前写成白纸黑字。答"没有",也干脆——代工档从你的地图上划掉,连"以后攒钱开厂"的念头一起划掉:那是一条资本和产能的赛道,不是手艺和勤奋的赛道(7.3.1的数学你今晚刚算过)。

**第二问,资金:你亏得起多少钱?**注意问的不是"你有多少钱",是"这笔钱亏光了,你的生活还转不转得动"。这个数直接圈定你离库存能有多近。亏得起十万以上、且能接受它压上一年——品牌档的门槛你摸得到,但7.3.3的三条件还要另外过;亏得起两三万——你可以做带小库存的电商现货(画像三的起手式,27.3有完整的现金流推演);只亏得起几千块——恭喜你,答案反而最清晰:**定制服务档几乎不需要你垫钱**,客户定金盖工厂定金(见14.5.1),你的启动成本是样品、色卡、机票和时间。钱少不是劣势,钱少却硬要站到吃库存的格子上才是。第9章之后你会反复看到:这个行业对轻资产的人出奇地友好,前提是你别去背不属于你的重。

**第三问,性格:你更享受跟人磨,还是跟货和数据磨?**这一问最容易被跳过,但它决定你能不能在一个档位里待满三年。定制服务档的日常是:时差里回邮件、翻译客户说不清的需求、在工厂和客户之间和稀泥、被放鸽子后笑着催款——**它本质是个乙方服务业**,享受搞定人的成就感的人如鱼得水,视沟通为消耗的人度日如年。电商品牌档的日常是:看数据、调listing、优化投放、研究评论区——对着屏幕跟转化率较劲,不用求任何人,也没有任何人可求。两种苦味完全不同,没有高下,只有合不合。画像二的老外贸底子适合前者,画像三的电商手感适合后者;都不沾的,从定制服务练起——**沟通是可以练的,性格里对"跟人打交道"的耐受度,练不出来,只能诚实面对。**

三问答完,把结果压成一句话,模板给你:"我有/没有工厂资源,亏得起__万,更享受跟人/跟数据磨——所以我站**__档**,赚**__**的钱,十二个月目标是__。"这句话就是你的定位声明,它不是终身判决——第27章会给三条路径各画一张12个月的路线图,做完第一年你有权重答;但在那之前,**一次只站一个格子**:这个行业淹死的人,多数是三个档位都想赚、每个都只伸了半只脚的人。

你在自己的笔记本上写下你的那句:"没有工厂,亏得起的钱不多,但我不怕跟人磨——定制服务档,赚服务费和信息差的钱,十二个月内,把 Mike 这样的客户做到二十个。"写完合上笔记本,窗外镇子北头那家大厂的灯还亮着——那是别人的格子,挺好,但不是你的。明天车缝线全面开动,后天开始你要在车间里泡上几天——地图看完了,该回到地面,去认识那些真正把帽子做出来的人。

## 本章工具

**工具一:价值链加价表(模板+本章两个实例)**

分析任何产品"谁赚走了什么"的固定表格。栏目:环节 → 拿货价 → 卖出价 → 加价幅度 → 该手承担的成本与风险。使用铁律:①每一手的加价≠利润,先填"承担什么"再下判断;②看到诱人价差,先数它横跨几手,再问自己顶替得了哪一手(见7.1.1)。

通用帽实例(¥15出厂→$29.99零售,约14倍):工厂 +8个点(设备工资垫资)→ 贸易商 +15个点(跟单担责收汇)→ 进口/品牌 约4倍(海运关税、库存、营销)→ 零售 约2.3倍(房租人力滞销)。

R&B 单实例(你压短了链条):工厂出厂¥17.5 → 你到门交付合¥23.9/顶成本 → 售 Mike 9.9加元(¥51.5),毛利率约54%(顶替了贸易+进口+分销三手,见7.3.2)→ Mike 吧台零售30加元,约3倍(自带流量,获客成本为零,见7.2.3)。

**工具二:三档位对比卡**

| | 走量代工 | 定制服务 | 自主品牌 |
|---|---|---|---|
| 赚什么钱 | 加工费 | 服务费+信息差 | 品牌溢价 |
| 核心公式 | 产能×开机率×单顶净利 | 客户数×单均毛利×复购 | 认知×流量×售罄率 |
| 毛利率量级 | 5-15个点 | 30-55% | 纸面70%+,净利看售罄 |
| 入场门槛 | 产能+资本 | 行话+流程+终端客户 | 已验证的款+库存资金+流量能力 |
| 天花板 | 产能与大客户议价 | 你的时间与客户数 | 现金流与认知 |
| 头号风险 | 开机率崩、点数被逐年砍 | 客户被直连、依赖个别大客 | 库存滞销、广告烧穿 |
| 适合谁 | 画像一(27.1) | 所有新人首选,尤其画像二(27.2) | 画像三,先C后B(27.3) |

**工具三:毛利率↔加价倍率换算卡(报价前必查)**

- 报价=成本÷(1−目标毛利率),永远用除法,不用乘法(见7.1.2)
- 毛利率=1−1÷倍率;倍率=1÷(1−毛利率)
- 速查:毛利20%↔1.25倍;30%↔1.43倍;40%↔1.67倍;50%↔2倍;60%↔2.5倍
- 听到"点"先问分母:"按卖价算还是按成本算?"
