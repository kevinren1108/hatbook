# 第19章 算账:全书最重要的一章

**主线推进** —— 货在太平洋上。第十天,货代小林发来一条船期更新:预计还有二十天靠港。这是从市集遇见 Mike 到现在,你第一次手上什么都不用干——工厂那边尾款付清了,单证交出去了,中国这头的报关和退税单证也递上去了(那笔退税归工厂,见18.3.2)。你把一个鞋盒倒在桌上:工厂的PI和收款收据、绣花制版的收据、四张国际快递单、洗水厂的结算条、货代那张三行报价单、两张银行入账通知、两张结汇水单,还有——你犹豫了一下才把它也放进去——两趟去山东的高铁票和酒店发票。

你原本以为这是十分钟的活:第7章那张分账表你早就算过了,收入4,950加元,成本11,950,毛利13,790,54个点。可真的把每张纸摊平、按日期排好、一张一张往表里录,有三样东西让你停了很久。一是验货那几天给 Mike 的让步邮件——折让80加元、¥416,这笔钱当初报9.9时根本不在脑子里。二是两趟山东的票据,加起来三千五,你从没把它当成"这一单的成本"。三不是纸,是你翻日历数出来的数字:从六月初到现在,你在这一单上真正花掉的时间。

台灯下你写下一行字:**估价是感觉,算账是证据。**这一章,你要把这单从头到尾算一遍——不是估,是把每一张单据摊开对着算。

## 19.1 到岸成本公式

### 19.1.1 landed cost逐项分解:货款+头程+关税税费+尾程+损耗

第7章那张价值链表里,进口商那一行写着"到岸约$3.30",后面跟了一个括号:landed cost,详19.1(见7.1.1)。现在到了兑现的时候。

先把定义钉死。**landed cost(到岸成本)**:一批货从供应商手里出发,到最终躺进收货方仓库(或客户门口)那一刻为止,你为它付出的全部现金,除以数量,就是单顶到岸成本。三个词是关键:**全部**(不是货款,不是货款加运费,是全部)、**现金**(实际流出去的钱,不是估的、不是"应该差不多")、**躺进仓库那一刻**(不是上船那一刻,不是清关那一刻)。

为什么必须用这个口径?因为这条链上每一段的报价口径都不一样(见13.3.3的三线图),而**只有到岸成本是唯一可以跨口径比较的数**。工厂报你FOB青岛¥17.5,加拿大本地供应商报 Mike 落地价14加元,亚马逊上一顶同款现货卖$12.99——这三个数根本不在一个坐标系里,只有全部换算成"帽子躺进温哥华那间酒厂仓库时,一顶到底花了多少钱",才能放在一起。**landed cost 是外贸人的公制单位。**

完整公式,八块,抄进笔记本:

```
到岸成本 Landed Cost =
   ① 货款           出厂价×数量 + 货款外单列的加工费
 + ② 一次性费用      制版/开模/样品/寄样/检测/差旅  ÷ 摊销基数
 + ③ 头程物流        国内段 + 主运费 + 附加费 + 保险 + 报关单证
 + ④ 关税税费        关税 + 进口环节税 + 清关代理费(+特别税)
 + ⑤ 尾程            目的港到门派送 + 入仓/预约/偏远附加
 + ⑥ 资金与汇兑      收款手续费 + 结汇点差 + 资金占用利息
 + ⑦ 损耗与售后备付   生产损耗 + 运输破损 + 折让退换 + 意外备付
 − ⑧ 退税抵减        谁报关退给谁(见18.3.1);你不报关,这行填 0
```

逐块拆开,每一块都还有子项,子项才是漏钱的地方。

**①货款**,看着最简单,坑在"货款外"。你以为货款就是¥17.5×500=¥8,750,可这单还有一笔轻酵素洗¥500(见3.3.3)——它是洗水厂外发,老纪的报价单上单列,不在¥17.5里。同类的还有:超出常规的包装升级、贴条码标(工厂贴标¥0.2-0.5/顶,见4.6.4)、加急插单费(订单额5-8%,见9.7.1)。**规则:凡是报价单上和单价分行写的,一律单独进表**,因为它们不随单价的数量阶梯下降。

**②一次性费用**,本章的头号杀手,19.5会单独算。它的特点是**与数量无关**:制版费¥200,做500顶是¥200,做100顶还是¥200(见3.1.5);打样和四趟国际寄样合计¥700(见10.4.2),数量减半也不会变成¥350。所以它的杀伤力等于"总额÷数量"——500顶时摊¥1.8/顶,100顶时摊¥9/顶,足足五倍。**摊销基数怎么定,是一个判断题**:保守派全摊进首单(这单赚不赚得回,一次见分晓);现实派摊进"预计十二个月内这个客户的总量"(制版是资产,翻单免费复用)。两种都对,但必须在表上写清你用的是哪种——**含糊的摊销,是自欺的开始**。

**③头程物流**,不等于"运费"两个字。它至少五层:国内段(工厂到货代仓的拖车或快递)、主运费(海运/空运/专线的干线)、附加费(燃油、旺季、超长超重、单证)、货运保险(见17.7)、出口报关与单证费。你这单为什么只有一个数¥1,400?因为你买的是专线的打包价(见17.4),五层全被卷进"按方计费"里了。**打包价的好处是省心,代价是你看不见结构**——19.4那个整柜例子会把这五层完整摊开给你看。

**④关税税费**,在你这单里同样"看不见"——双清包税的运价里包含了目的国清关和税(见17.4)。但看不见不等于没有:500顶货值折加元约CAD 1,670,按加拿大对纺织帽类的MFN税率16%(见18.4.1)算,关税本身就是CAD 267≈¥1,388,合¥2.78/顶——几乎正好等于你付的整个¥2.8运价。这个反差19.4会正面处理,它是理解"包税专线为什么便宜"的钥匙。

**⑤尾程**,目的港/目的机场到客户门口那一段。整柜和拼箱要单独付(温哥华港到市区仓库一趟CAD 400-600),专线和快递含在报价里。它的隐藏子项是**偏远附加与二次派送**:客户地址是工业区、收货没人签、要预约卸货窗口——每一条都能加出几十上百加元。

**⑥资金与汇兑**,第14章整章讲过机制,这里只管落到表上:中转行扣费(你这单两笔共60加元,见14.1.1)、结汇点差(0.3-0.5%)、以及最容易被忘的**资金占用**——你垫出去的钱在外面待了多久,乘以你的资金成本。

**⑦损耗与售后备付**,唯一一块"还没发生就要先记账"的成本。生产损耗2-3%(见9.6.1)已经在工厂报价里了,你要备的是三样:运输破损、客户折让(你这单实际发生了80加元,见11.6.2)、意外(第18章那笔查验杂费CAD 150,此刻还在未来,但你现在就该给它开一行)。

**⑧退税**,是唯一的减项。13%的出口退税(见9.7.3)跟着报关单抬头走,**谁报关退给谁**。这一单是工厂自营出口(见8.1.1),退税归工厂,已经体现在它敢报¥17.5这个薄价里;你的表上这一行,就是0。等你自己有了进出口权,这一行会变成表里最大的一笔正数——这也是第25章要谈"生意正规化"的原因之一。

现在把八块套回你这一单,得到本节的落点:出厂价¥17.5,单顶到岸成本¥23.90(见7.3.2那张表),**中间隔着¥6.4,涨幅36.6%**。这6块4就是本章的全部主题——它是你敢报9.9的底气,也是你差点亏钱的地方。

本节动作:现在就把上面那八行抄成一张空表,八个大项、每项留三到五行子项,存成"到岸成本核算表 v1"。以后任何一单开工前,先把这张空表打开,填不满的格子逐个去问——**问不出来的格子,就是你这单的风险敞口。**

### 19.1.2 每个数从哪来:对应单据与查询渠道

上一节给了你一张八块的表;这一节回答一个更要命的问题:**表里每一格的数,凭什么是那个数?**

先讲一条纪律,本章最硬的一条:**没有出处的数字不许进表。**不是"大概两千"、不是"货代说差不多"、不是"上次好像是这个价"——每一格背后必须站着一张纸或一个可复查的链接,并且这张纸上要有日期。理由很简单:成本表不是给你自己看的,它是你报价的地基;地基里掺了估计值,你报出去的价就是一个估计值,而客户付给你的钱是精确到分的。

逐项对表,这张表建议你直接复制到核算表的"取数来源"列里:

| 成本行 | 取数单据/渠道 | 由谁出具 | 关键核对动作 |
|---|---|---|---|
| 货款 | 工厂PI/形式发票 + 出货对账单 | 工厂业务(老纪) | 单价、数量、币种、是否含税含运;与9.1.1的四栏拆分对得上 |
| 货款外加工 | 加工厂结算条(洗水/贴标/后整) | 外发厂或工厂代收 | 是否按顶计、有无最低一缸/最低批量 |
| 制版/开模 | 制版收据 + 版权归属说明 | 工厂或绣花厂 | 是否一次性、翻单免不免、.dst文件是否交付(见3.1.6) |
| 打样与寄样 | 快递运单 + 打样费收据 | 快递公司/工厂 | 单号可查、重量与费用对得上;哪几票能让客户到付(见10.4.2) |
| 头程运费 | **货代书面报价单**(PDF/邮件) | 货代(小林) | 计费方式、有效期、含哪些不含哪些 |
| 关税税费 | HS编码 + 目的国税则查询截图 | 你自己查 | 税号6505类目(见18.1.1)、MFN税率、是否有协定优惠 |
| 进口环节税 | 同上 + 清关行费率表 | 清关行 | GST/VAT能不能抵扣(见18.4.1) |
| 尾程派送 | 货代报价单的派送行 或 快递账单 | 货代/快递 | 是否偏远、有没有预约费和二次派送费 |
| 收款手续费 | **银行入账通知/MT103水单** | 银行 | 到账金额与客户汇出金额之差,就是中转行扣了多少(见14.1.1) |
| 结汇损失 | 结汇水单 | 银行 | 结汇牌价与当日中间价之差=点差 |
| 资金占用 | 你自己的资金流水表 | 你自己 | 垫资峰值×占用月数(见14.5.1那张时间表) |
| 折让/售后 | 客户书面同意邮件 + 让步接受记录 | 客户 | 金额、扣款方式(减尾款还是退款) |
| 生产损耗 | 验货报告 + 装箱单 | QC/工厂 | 实际入箱数与下单数之差 |

带你看三个最容易出问题的格子。

**第一个,运费。**运费必须是**书面报价单**,不能是微信语音里那句"两千八一方"。真实质感的一段对话,发生在很多新人身上:

> 你:"小林,0.48方到温哥华门到门,多少?"
> 小林:"两千九一方,你这票一千四。"
> 你(记下¥1,400,报价发出去了)
> 十天后账单来了:海派运费¥1,392,**出口报关费¥150/票,仓储操作费¥80,单证费¥50**,合计¥1,672。
> 你:"不是说一千四吗?"
> 小林:"运费是一千四啊,报关和操作费是另外的,大家都这样。"

他没骗你,他答的是你问的那个问题。**病根在你的提问方式**——你问的是"多少钱",该问的是"门到门全包,除了这个数我还要付什么"。所以给你一句原样可抄的话术:"这个价是**门到门全包**吗?报关费、操作费、单证费、燃油附加、目的港杂费、派送费,有没有哪一项是另外收的?麻烦发我一份写清楚的PDF,注明有效期。"——把这句话发过去,对方回你一份PDF,那份PDF才是你表里那一格的出处。这也是13.5为什么要求物流段按报价的1.15-1.2倍计入:**书面报价之外总还有零头,buffer 就是给零头准备的。**

**第二个,关税。**关税这一格的出处不是任何人的嘴,是两样东西:**HS编码**和**目的国税则表**。编码怎么定见18.1.1,查询渠道记住三个:加拿大查 CBSA 的 Customs Tariff、美国查 USITC 的 HTS、欧盟查 TARIC——都是官网、都免费、都能查到具体税号下的MFN税率和有无协定优惠。查完**截图存档,文件名带日期**,因为税率是会变的。任何一个货代或清关行给你口头报"大概十几个点",都只能当参考,不能进表。

**第三个,汇兑。**这一格新人最爱拍脑袋,其实它是全表出处最硬的一格——银行的入账通知上明明白白写着客户汇出多少、你到账多少,两个数一减就是中转行扣费;结汇水单上写着结汇牌价,和当天中间价一比就是点差。你这单两笔加起来是¥388(见14.5.1),不是"大约1.5%"——**1.5%是你报价时的计提,¥388是事后的实账,两个数都要留在表上,差额就是你计提得准不准的成绩单。**

最后给你一条把纪律变成习惯的做法:**在Excel的每一个输入格上加批注**(右键"插入批注"),批注只写两行——来源、日期。比如运费格的批注:"小林2026-07-15报价PDF,有效期30天"。三个月后你回头看这张表,不用回忆,不用翻聊天记录。19.7会把这个做法固化进模板。

本节动作:把你手上正在跑的那一单,按上面这张表逐行去要单据——缺哪张要哪张。要完之后做一件事:**把每一格的数和它的单据对一遍,记下所有对不上的差额。**这些差额加起来,就是你此前"凭感觉"的误差范围;知道了这个范围,你才知道自己的报价该留多厚的余地。

## 19.2 算例一:100顶空运快递(体积重演示)

三张纸摊完,你顺手在笔记本上出了三道自测题。**第一题:如果 Mike 当初只要100顶试单,而且赶着八月初的一场小活动,只能走快递,这单该怎么算、该报多少?**

先算物流,因为这一题的全部机关都在这里。

100顶,按嵌套8顶一摞、100顶一箱的装法(见4.6.2),正好**1箱**:60×40×40cm,0.096CBM,连箱毛重**12.5公斤**。你打开快递公司的报价页面,准备按12.5公斤算钱——这是新人踩的第一个坑。

**体积重**的原理17.3.1已经讲透,这里只做一件事:算给你看。飞机和快递车卖的不是重量,是空间;一个装满羽毛的箱子和一个装满钢块的箱子占同样的舱位,凭什么收一样的钱?于是行业造了一个换算:把体积折算成一个"假想重量",跟实际重量比,**谁大按谁收**。换算用一个除数:

```
空运(航空货运)体积重 = 长×宽×高(cm) ÷ 6000     即 CBM × 167
国际快递(DHL/FedEx/UPS)体积重 = 长×宽×高(cm) ÷ 5000   即 CBM × 200
计费重 = MAX(实际毛重, 体积重)
```

代进你这一箱:

```
空运体积重 = 60×40×40 ÷ 6000 = 16.0 公斤
快递体积重 = 60×40×40 ÷ 5000 = 19.2 公斤
实际毛重   = 12.5 公斤
计费重     = MAX(12.5, 19.2) = 19.2 公斤 → 快递按0.5进位 = 19.5 公斤
```

**你实际交给快递12.5公斤的货,付的是19.5公斤的钱——多付56%。**这不是被宰,这是规则;不知道规则的人才被宰。

再往深挖一层,得到一个关于这个行业的重要结论。把你这箱货的密度算出来:12.5 ÷ 0.096 = **130公斤/立方米**。而快递的分界线是200、空运是167——**帽子的密度低于所有分界线,帽子天生是抛货。**这句话值得写进你的笔记本第一页,因为它决定了三件事:第一,帽子的物流成本永远按体积算,货值再高也没用;第二,4.6.2里"嵌套装箱"那个手法之所以值这单毛利的10%,根源就在这里;第三,你没法靠压缩解决它——软顶dad hat压狠了留折痕,定型白做(压缩的度见17.3.2)。**别人做电子产品可以在重量上省钱,你做帽子只能在体积上省钱。**

单价怎么取?中国到加拿大的商业快递,重量分档,越重单价越低:21公斤以下是最贵的一档,渠道价(货代代理的折扣价,不是官网价)大约**¥60-80/公斤**;100公斤以上能降到¥40-50/公斤(所以ch15里算500顶改空运时用的是"一公斤四五十块",两个数不矛盾,是两个重量档)。这一票19.5公斤,取中间值¥70:

```
快递运费 = 19.5 × 70 = ¥1,365     单顶物流成本 = ¥13.65
```

对比你实际走的海派:¥2.8/顶(见13.3.2)。**空运快递是海派的4.9倍。**

接着补两个小单特有的坑,然后表就完整了。

**坑一:最低消费。**轻酵素洗按¥1/顶算,100顶是¥100——洗水厂不会为你开一缸。行规是**最低一缸起收,约¥300-500**,你这票按¥400。同理,海派专线也有最低计费方数(约0.3方或最低收费¥800上下,见17.2.1的LCL同理),所以100顶就算走海派也不是0.096×2,900=¥278,而是按最低收¥870。**小单的世界里,处处是最低消费。**

**坑二:税。**快递不是不交税,是快递公司替你交了再向你收。货值CAD约335,加拿大低值货物简化清关下,关税16%约CAD 54、GST 5%约CAD 19、快递公司代垫手续费CAD 10-20,合计约**CAD 88≈¥458**(见18.4.1)。这里有个真实的坑要提前说:如果你的快递单没有勾DDP,这张税单会直接寄到客户门口——**客户以为"包税到门",结果开门被要钱**,是快递小单最常见的客户体验事故。所以:**报价里写清含不含税,快递面单上勾DDP,两处都要做。**

完整到岸成本表:

| 成本行 | 金额(¥) | 折每顶(¥) | 取数来源 |
|---|---|---|---|
| 货款 100×17.5 | 1,750 | 17.50 | 工厂PI |
| 轻酵素洗(最低一缸) | 400 | 4.00 | 洗水厂结算条 |
| 绣花制版费(一次性) | 200 | 2.00 | 制版收据 |
| 打样与寄样(一次性) | 700 | 7.00 | 快递运单×4 |
| 国际快递 19.5kg×¥70 | 1,365 | 13.65 | 快递渠道报价单 |
| 进口关税+GST+代垫费 CAD 88 | 458 | 4.58 | 税则表+快递账单 |
| **小计(不含换汇)** | **4,873** | **48.73** | |

现在做定价。假如你还按9.9加元报:收入100×9.9×5.2=¥5,148,换汇1.5%=¥77,总成本¥4,882,**毛利¥266,毛利率5.2%**。同样一个9.9,500顶时是54个点,100顶时只剩5个点——**一次查验、一顶返修、一次二次派送,这单就归零甚至倒贴。**

那该报多少?按45%的目标毛利率倒推(公式见7.1.2:报价=成本÷(1−目标毛利率)),答案是**CAD 17/顶**:收入¥8,840,换汇¥133,总成本¥4,938,毛利¥3,902,**44.1%**。

盯着这个17看三秒,你会看到本节最有价值的那句话:**本地促销品渠道的报价是12-16加元(见5.5.2)——你的17,已经贵过了 Mike 家门口的供应商。**也就是说,在100顶这个量级上,**你相对本地供应商的成本优势不存在了**,一次性费用和小票物流把它全吃掉了。

所以"什么时候值得空运/走快递",三条判断规则,直接用:

**规则一,看单顶差价换来的天数值不值。**快递¥13.65 vs 海派最低收费口径¥8.70,差¥4.95/顶≈0.95加元,换来的是25天。问客户一句话就有答案:"提前三周半到,值不值0.95加元一顶?"——办活动的客户答"值",补库存的客户答"不值"。**把时间明码标价,谈判就不再是拉锯。**

**规则二,看量级阈值。**200顶以下、或者交期不足35天,走快递(专线的最低消费和28-32天时效在这里都不划算);500顶以上且时间够,走海派;超过10方,算整柜(见17.2.3)。

**规则三,看一次性费用的摊销分母。**这一票真正的杀手不是快递费¥13.65,是制版+寄样的¥9/顶。**同样这900块钱,500顶时摊¥1.8,100顶时摊¥9**——所以小单的正确解法不是压运费,是**要么把一次性费用向客户单列收取**(制版费在报价单上单独列一行,见15.2),**要么把摊销基数放到十二个月的预计总量上**并在心里接受首单不赚钱。

本节动作:打开快递公司的官网价目表,查一次中国到你目标市场的21公斤档单价,再用你自己产品的一个标准箱尺寸算一遍体积重和密度。密度低于167的,在你的产品资料上永久标注一行:**"抛货,物流按体积计费"**——以后每次报价,这行字会替你省下真金白银。

## 19.3 算例二:1000顶海派专线

**第二题:同样的帽子、同样的通道,数量翻一倍到1000顶,该报多少?**

这一题看着简单——不就是把 R&B 那张表乘以2吗?算完你会发现,乘以2的只有两行,其余全变了,而**变化的方向和幅度,正是"规模效应"这四个字的真实含义**。

先算物流。1000顶=**10箱**=0.96CBM;毛重10×12.5=125公斤。先做一次密度校验:125÷0.96=130公斤/立方米,还是抛货,还是按方计费(专线按方还是按重,取的也是MAX,只是除数比快递宽松)。运费:

```
0.96 方 × ¥2,900/方 = ¥2,784      单顶物流 = ¥2.78
```

停在这里。500顶时是¥2.80,1000顶时是¥2.78——**量翻了一倍,单顶运费只降了两分钱。**这是本节的第一个反直觉结论:**按方计费的专线,运价对量是线性的,量本身不产生任何规模效应。**新人最爱在运费上抠,以为量大了运费就便宜,其实要等到货量大到能换通道(拼箱转整柜,见17.2.3)才有台阶,在同一个通道里,方价就是方价。

那规模效应从哪来?从另外三个地方,一个一个算。

**第一处,货价的数量阶梯。**老纪的报价单上写着:3,000顶¥16.6、10,000顶¥16.0(见9.7.1)。1,000顶落在500和3,000之间,按这条线插值并留一点谈判空间,取**¥17.0/顶**——比500顶的¥17.5降¥0.5。这¥0.5不是老纪发善心,是9.1.1里那八层拆解中"管理摊销"和"损耗"两层被摊薄的结果:同样一次排产、一次换线、一次首件确认,分摊到1,000顶和500顶,差的就是这几毛。

**第二处,一次性费用的摊销。**制版费¥200、打样与寄样¥700、两趟山东¥3,500——合计¥4,400,与数量完全无关。500顶时摊¥8.80/顶,1,000顶时摊¥4.40/顶,**一刀砍掉一半**。这是规模效应真正的主力。

**第三处,备付项的性质差异。**折让和换汇是按售价百分比走的(量大了绝对额同比增,单顶不变),但"意外备付"是按票走的——一票查验就是CAD 150左右,不管你这票是500顶还是1,000顶。所以¥800的意外备付,500顶时摊¥1.60,1,000顶时摊¥0.80。

把三处合起来,列完整的到岸成本表。场景设定说清楚:**新客户、新logo、首单1,000顶**(所以制版、打样、差旅一样不少),报价按后面19.6.2的阶梯定为**CAD 10.5/顶**:

| 成本行 | 金额(¥) | 折每顶(¥) | 相对500顶的变化 |
|---|---|---|---|
| 货款 1,000×17.0 | 17,000 | 17.00 | −0.50(数量阶梯) |
| 轻酵素洗 ¥1×1,000 | 1,000 | 1.00 | 持平 |
| 绣花制版费 | 200 | 0.20 | −0.20(摊销) |
| 打样与寄样 | 700 | 0.70 | −0.70(摊销) |
| 差旅(两趟山东) | 3,500 | 3.50 | −3.50(摊销) |
| 海派专线 0.96方×¥2,900 | 2,784 | 2.78 | −0.02 |
| 收款与换汇 1.5%×收入 | 819 | 0.82 | 随售价 |
| 折让与售后备付 1.5%×收入 | 819 | 0.82 | 新增计提 |
| 意外备付(每票¥800) | 800 | 0.80 | −0.80(按票摊销) |
| 资金占用(峰值¥4,400×1.5月×年化12%) | 66 | 0.07 | — |
| **到岸成本合计** | **27,688** | **27.69** | |
| 收入 1,000×10.5加元×5.2 | 54,600 | 54.60 | |
| **毛利** | **26,912** | **26.91** | **49.3%** |

现在把"规模效应"这四个字的账拆干净。单顶到岸成本从500顶口径的¥33.28(完整口径见19.5)降到1,000顶的¥27.69,降了¥5.59。这¥5.59从哪来?

```
差旅摊销   −3.50   (61.6%)
意外摊销   −0.76   (13.4%)
寄样摊销   −0.70   (12.3%)
货价阶梯   −0.50   ( 8.8%)
制版摊销   −0.20   ( 3.5%)
运费       −0.02   ( 0.4%)
──────────────────────
小计       −5.68   (再叠加换汇、折让、资金三项按售价计提的微调 +0.08,净 −5.59)
```

**运费只贡献了千分之四。**而摊销类(差旅+意外+寄样+制版)加起来贡献了90.8%。这个分解应该改变你的行为:下一次接到一单量翻倍的机会,你该花力气去谈的不是运价,是**能不能免掉制版费、能不能让客户承担寄样、这一趟能不能一次跑三个客户把差旅摊掉**。

对话时刻,把这个认知变成谈判话术。客户问:"我要1,000顶,你能便宜多少?"新人的答法是"我给你算一下运费"——错。你的答法:

> "500顶报11.5,1,000顶我给你10.5,便宜一加元。这一加元不是我少赚了,是三笔钱被摊薄了:制版费一次性200,打样寄样700,再加上我为这个单跑工厂的成本——这些钱做500顶和做1,000顶是一模一样的,你量大一倍,它们每顶就少一半。**运费我一分钱没省,因为按体积算,你的货翻倍运费也翻倍。**"

这段话有三个作用:它是真话;它让客户看见你的成本结构从而信任你的报价;它顺手教育了客户"下次要更便宜就再加量",把加量的动机种进去。**能把自己的成本结构讲明白的人,不需要跟客户吵价格。**

最后留一个判断给你。1,000顶0.96方,离拼箱转整柜还很远(20方以上才该算整柜,见17.2.3),但已经到了另一个岔路口:0.96方这个量,**海运拼箱LCL**(见17.2)可能比海派专线便宜三到四成,代价是你要自己搞定目的港杂费、清关和派送——也就是13.3.2里 Mike 不愿意碰的那一堆事。规则给你:**你的客户是终端(不懂进口)就走专线,客户是有清关能力的进口商就报CIF让他自己接;别把清关的活揽到自己身上,除非你收了这份钱。**

本节动作:把你手上任何一个产品,做一张"三档量的单顶到岸成本对比表",三档自己定(比如300/1,000/3,000)。做完只看一件事:**从第一档到第三档,降下来的钱里有几成来自一次性费用摊销?**这个比例告诉你,你的生意到底是"靠量压成本"还是"靠量摊费用"——两者的谈判策略完全不同。

## 19.4 算例三:一个整柜(规模效应)

**第三题:一个整柜。**

这道题你三年之内可能都碰不到,但必须算一遍——因为它是你所有价格判断的**远端坐标**。不知道整柜的成本长什么样,你就永远不知道自己在链条上的成本劣势有多大,也就无法理解为什么第0章那顶帽子的到岸价能做到$3.30(见7.1.1)。

先装柜。40HQ(40英尺高柜)内容积约76立方米,实际装载率85-90%,可用**约68CBM**(柜型与装柜估算见17.1.1)。你的标准箱0.096CBM:

```
可装箱数 = 68 ÷ 0.096 ≈ 708 箱 → 取整 700 箱
可装数量 = 700 × 100 = 70,000 顶
总毛重   = 700 × 12.5 = 8,750 公斤 = 8.75 吨
```

第二次密度校验,这次的结论会让你会心一笑:40HQ的载重上限约26吨,你只用了8.75吨——**一整个柜子装满了帽子,重量只用掉三分之一。**抛货的性质在整柜这个尺度上依然成立,而且更有画面感:一个四十尺的铁盒子,塞满七万顶帽子,还没有装三分之一的水泥重。这就是为什么帽子行业的柜子永远是"体积爆了重量还早得很",也是为什么行内谈整柜只谈方数不谈吨位。

现在把物流五层完整摊开——这是你第一次看见13.5那张"打包价"背后的真实结构:

| 段 | 费用项 | 金额 | 折¥ | 说明 |
|---|---|---|---|---|
| 国内 | 拖车 胶州→青岛港(约1小时,见6.2.1) | ¥1,200 | 1,200 | 一柜一车 |
| 国内 | 出口报关+单证+电放 | ¥800 | 800 | 按票 |
| 国内 | 港杂(THC+封条+文件) | ¥1,300 | 1,300 | 按柜 |

```

**四毛六。**海运费在$2,000-4,000之间波动时,这个数在¥0.37-0.57之间——无论怎么波,都是"几毛钱"。

现在把三个算例并排放在一张表上,这是全章最该被拍下来存进手机的一张:

| | 100顶快递 | 500顶海派 | 1,000顶海派 | 70,000顶整柜 |
|---|---|---|---|---|
| 通道 | 国际快递DDP | 海派专线双清 | 海派专线双清 | 海运整柜FCL |

| 单顶货款外加工(洗水) | 4.00 | 1.00 | 1.00 | 1.00 |

还有一件事必须在这里说清楚,它是本章最重要的一段风险提示。回看那张对比表的"关税税费"行:整柜那一列老老实实写着¥2.56/顶(货值¥16.0×16%,见18.4.1),而500顶那一列写的是"含在运价内"。可你算算——500顶的正规关税是¥17.5×16%=¥2.80/顶,**和你付的整个海派运价¥2.80一模一样**。也就是说,如果这500顶走正规报关自税路线,光是关税¥1,388,加上13.3.2里列的那堆目的港杂费、清关代理费和派送费(CAD 400-600),总共要CAD 600-850≈¥3,100-4,400,合**¥6.2-8.8/顶**——是你实付¥2.8的两到三倍。

差额从哪来?**不是货代比你会砍价,是包税专线在目的国清关时用的是它自己的申报口径**,这正是17.4要专门讲"双清包税的灰色"的原因。作为使用者,你必须清楚三件事:第一,你买的是一个打包服务,税的部分不透明;第二,一旦被查,货可能被扣、补税罚款的最终责任会顺着链条找回来(见18.5);第三,**这条通道适合小票试单,不适合你把生意做大以后的常态**——货量上来、客户变成正经进口商之后,正确的路是报CIF或FOB,让客户做进口人(见13.3.2),或者你自己在目的国注册税号走正规完税。判断阈值给你:**同一个客户累计出货超过20方,或者单票货值超过CAD 10,000,就该把通道从"包税专线"切换到"正规报关+客户自税"。**便宜和干净之间,规模会替你做选择。

本节动作:找一家货代,报一次你自己产品的整柜价——哪怕你现在根本装不满一个柜。要来之后,把单顶物流成本算出来,写在你的成本表最底下一行,标注"远端坐标"。以后每次有人跟你比价,先看看对方的量在哪一档;**跨档比价是没有意义的,而知道每一档的坐标,是你唯一不会被唬住的办法。**

## 19.5 七项常漏成本

三道题做完,你回到自己这一单,把鞋盒里剩下的那几张纸也录进表。这一节,是本章的心脏。

第7章那张分账表算出成本¥11,950、毛利¥13,790、54个点(见7.3.2)。那张表没有错——它把你付给工厂、洗水厂、货代、银行的每一笔钱都记上了。但它漏了七项。逐项算,每项给出量化方法,最后合计。

**第①项:样品与寄样费。**你这单¥700(见10.4.2),占毛利5.1%。它已经在¥11,950里,列在这里是因为它是**最容易在报价时被忘的一项**——报价发生在打样之前,你脑子里只有"帽子多少钱一顶",而打样的钱是后来一笔一笔漏出去的。量化方法:**按"预计轮数×每轮成本"预估**,开发样¥80-150/顶、每轮国际快递¥150-280(见10.4.2),常规两到三轮,预算¥600-900。降低它的动作只有两个:样品费该收就收、寄样用客户的到付账号(见10.4.2)——14.5.1里那句"这¥700其实有一部分可以要求 Mike 承担,你当时为了促成第一单自己吃了",说的就是这里。

**第②项:一次性开发费用。**制版费¥200(见3.1.5),占毛利1.5%。帽子这个品类算便宜的,换成开模的产品(定制五金扣、定制织唛版费、定制印刷袋版费¥100-200,见4.6.1)动辄上千。量化方法:**列一张"与数量无关的费用清单",合计后除以摊销基数**;基数取首单量还是十二个月预计量,在表上注明(见19.1.1)。这单按首单500顶摊是¥0.40/顶。

**第③项:汇兑损失与手续费。**实账¥388(见14.5.1),占毛利2.8%。拆开看:中转行扣费60加元(定金被扣45、尾款被扣15,BEN条款的代价,见14.1.1)折¥312,结汇点差约¥76。量化方法:**按收款总额的1.5-2%计提**(小额、多笔、走第三方收款的取上限,PayPal综合能到7.5-8%,见14.4)。这一项有个特点:**它随收入增长而绝对增长,但比率稳定**,所以它是所有漏项里最容易预估的一项——没有理由漏。

**第④项:资金占用成本。**你这单的垫资峰值是¥900(见14.5.1),占用约三周;按年化12%(个人经营资金的合理机会成本)算:900×12%×(3/52)≈**¥6**。六块钱,可以忽略——但**你必须知道它为什么可以忽略**:因为你站在定制服务档、加价倍率接近3、客户定金2.84倍覆盖工厂定金(见14.5.1)。换成14.5.1里那个反例(客户定金20%、工厂要50%、缺口¥29,000、占用三个月),资金成本是29,000×12%×0.25=¥870,吃掉那单¥15,000毛利的5.8%。量化方法:**垫资峰值 × 占用月数 × 月息(年化÷12)**;年化利率取你真实的资金来源成本(自有资金取10-12%的机会成本,借来的按实际利率)。**规则:任何一单在报价前先画14.5.1那张余额表,余额线的最低点乘以时间,就是这一项。**

**第⑤项:售后与折让。**事故一的让步接受,折2加元/顶×40顶=80加元=**¥416**(见11.6.2),占毛利3.0%。这一项还有个"没花到你钱但差点花到"的兄弟:拆绣重绣80顶的返工费约¥600,老崔主动担下来了(见11.6)——**这次是运气,不是制度**;如果工厂不认,这¥600就是你的。所以量化的时候要按"可能落到你头上"来备,不是按"上次没花到"来备。量化方法:**按售价的1-1.5%计提**,首次合作的工厂、新工艺、颜色敏感的单取上限。¥25,740×1.5%≈¥386,和实际发生的¥416几乎吻合——**这不是巧合,1.5%这个数就是从这类真实事故里长出来的经验值。**

**第⑥项:意外费用。**第18章那笔加拿大海关查验的杂费**CAD 150≈¥780**(见18.4.1),占毛利5.7%。写这张表的此刻,货还在海上,这笔钱还没有发生——**而这正是本项的教学价值:意外费用的正确记法,是在它发生之前就在表上开一行。**你不知道会不会被查,但你知道被查的概率不是零(随机查验率通常在百分之几的量级),也知道被查一次的代价是三五天延误加一两百加元。量化方法两选一:**按售价1%计提**,或**按每票固定¥500-800**;小票用后者(因为查验费按票不按量)。19.6.2会告诉你这笔备付该从报价的哪几个点里出。

**第⑦项:你自己的时间成本。**这是七项里唯一不涉及现金、却最大的一项。翻手机日历数一遍:需求沟通与选料约30小时(第1-3章那些事)、找厂询价打样约40小时(第9、10、12章)、驻厂验货与两趟差旅约60小时、单证物流收款约25小时、事故处理与售后约15小时——**合计约170小时**。按你上一份工作折算的时薪¥100算,**¥17,000**。另外,这两趟山东的高铁与住宿是真金白银的**¥3,500**,7.3.2里那句"两趟中国的机票住宿几千块"就是它,而它从来没进过任何一张成本表。

现在合计。**已经在¥11,950里的**:样品¥700、制版¥200、汇兑¥388(表上记的是¥400)。**表外的四项现金**:

```
差旅          ¥3,500
客户折让      ¥416
海关查验备付  ¥780
资金占用      ¥6
────────────────────
表外现金合计  ¥4,690
```

于是这一单的真实账变成:

| 口径 | 收入(¥) | 成本(¥) | 毛利(¥) | 毛利率 |
|---|---|---|---|---|
| 第7章账面口径 | 25,740 | 11,950 | 13,790 | **53.6%** |
| **完全成本口径** | 25,740 | 16,640 | **9,100** | **35.4%** |
| 再扣自己的时间(170h×¥100) | 25,740 | 33,640 | −7,900 | — |

三行,三个真相。

**第一行是你告诉朋友的数字。**它不假,但它只统计了"付给别人的钱"。

**第二行是你该拿去做决策的数字。**35.4%——**表外那四项吃掉了毛利的34%**。这里插一句对账纪律,是新手最常犯的错:给 Mike 的折让80加元,要么从收入里减(4,950→4,870,见14.5.1的结算口径),要么记进成本(¥416),**只能记一次**;两边都记,你会平白多亏¥416,而这种重复计算在手工做的成本表里极其常见。

**第三行是学费。**首单的170小时里,至少有120小时是**一次性的学习成本**:第一次看面料卡、第一次读报价单、第一次做验货清单。翻单时这些时间不会再花——同样一单,翻单大约50小时,而且没有差旅、没有制版、寄样减半。所以第三行不该让你沮丧,它该让你看清一件事:**这门生意的第一单几乎注定不赚钱,它赚的是一套可复用的流程;你的利润全在第二单以后。**这也是为什么第五部要用整整四章讲获客——**流程是一次性成本,客户是重复收益。**

最后把七项压成一条可以直接用的报价规则:

```
报价时,在成本之上额外预留 5-8 个百分点,专门覆盖:
  折让与售后    1.0-1.5%
  意外与查验    1.0%
  汇兑波动      1.0-2.0%
  一次性摊销误差 1.0-2.0%
  资金占用      0.5-1.0%
量小、新工厂、新工艺、新目的国 → 取上限;
老客户翻单、成熟工艺、老通道 → 取下限。
```

本节动作:把你已经做过的任何一单(哪怕是一次帮朋友代购),按这七项重算一遍,重点填第④和第⑦项——**这两项从来没有单据,只能靠你自己诚实。**算完,把"完全成本口径毛利率"写在这单的档案封面上。以后每次有人说"这个生意毛利五十个点",你的第一反应会变成一个问题:**哪个口径的五十个点?**

## 19.6 定价

### 19.6.1 成本加成vs市场锚定:两种定价的适用场景

算完成本,该回答那个从第0章就悬着的问题了:**9.9这个数,当初到底是怎么来的?**

诚实的回答会让你自己吃一惊:**它不是算出来的。**你没有拿成本¥23.9去除以(1−目标毛利率),你是先看了一眼本地促销品渠道12-16加元的报价(见5.5.2),再看了一眼 Mike 说的12加元预算,然后在心里找了一个"明显比他现有选择便宜、又不至于低到让他起疑"的数——9.9。**这是两种定价法里的第二种,而你当时甚至不知道它有名字。**

两个名字,现场定义。

**成本加成(cost-plus)**:从自己的成本出发,加上目标利润,得出报价。公式7.1.2已经给过——报价=成本÷(1−目标毛利率)。它的逻辑起点是"我要赚多少",答案在你手里。

**市场锚定(market anchoring)**:从市场已经存在的价格出发,选定一个参照价(锚),再决定自己站在锚的上方还是下方多少,倒推回去检查成本能不能支撑。它的逻辑起点是"客户愿意付多少",答案在市场手里。它的严格版本在制造业里叫**目标成本法**:先定卖价、减去目标利润、得出"允许成本",然后逼着设计和采购做到这个成本——反过来倒推整条链。

两种方法不是水平高低之分,是**信息条件之分**。判断用哪一种,只看一件事:**客户手里有没有可比价?**

| 情形 | 用哪种 | 为什么 |
|---|---|---|
| 全新品类、独家工艺、无参照物 | 成本加成 | 客户无从比价,你的成本是这场对话里唯一的坐标 |
| 高度定制(客户的logo、客户的规格) | 成本加成为主 | 世上没有第二件一样的东西,可比性天然被削弱 |
| 红海标品(空白棒球帽、现货贴牌) | 市场锚定 | 你的成本与成交价无关,阿里页面上的价就是价 |
| 客户手里已有两三家报价 | 市场锚定 | 你不是在定价,你是在这几个数中间选位置 |
| 终端小B定制(Mike这种) | **锚定为主,加成设地板** | 他有本地替代品可比,但比不了中国出厂价 |
| 大客户招标 | 锚定+成本地板 | 必须提前算好walk-away价,守不住就退场 |

现在用这张表复盘你给 Mike 的9.9,能看出两处对、一处错。

**对的第一处:选对了方法。**Mike 手上有可比价——他自己说的"本地报价12起";你的成本(¥17.5出厂价)他永远看不到也理解不了。这种局面下用成本加成是自废武功:你把¥23.9除以(1−54%)得出¥51.9=9.98加元,数字巧合地接近,但这是**倒果为因**——你真正的定价动作发生在"看见12-16加元"那一秒。

**对的第二处:锚的位置选得有说服力。**9.9对12的预算,低17.5%;对本地最低价12,同样低17.5%。这个幅度很讲究:低5%,客户觉得"差不多,懒得换供应商";低40%,客户开始怀疑质量或者你会不会跑路。**行业经验值:相对客户现有选择便宜15-25%,是"值得为你冒一次险"的甜蜜区。**再加上心理定价的小手法——9.9而不是10,让它落在个位数,客户脑子里存的是"不到十块"。

**错的那一处,也是这一节最贵的一课:锚定得太低了。**Mike 的预算是12,本地最低是12。你报9.9,等于在他愿意付的价格上主动让掉了2.1加元。这2.1加元乘以500顶,是**1,050加元≈¥5,460**——比你这单表外漏掉的四项成本(¥4,690)还多。

怎么知道自己报低了?给你一个不需要任何情报的信号,也是本节最实用的一条:

> **如果客户第一次收到报价就接受、不还价、不犹豫,你大概率报低了5-15%。**

回想 Mike 那封回信——"Looks good, let's do it."没有还价,没有"能不能再便宜点",甚至没有等一天。买家的天性是还价,一个不还价的买家在告诉你:**这个数低于我的心理价位太多,我怕你反悔。**这不是玄学,是谈判的基本行为学。

反过来的翻车案例也给你,数字是全的。一位同行接美国客户3,000顶渔夫帽,完全成本$3.20/顶,他用纯成本加成、目标毛利30%,报$4.57。客户当天回"Approved, please send PI"。他高兴了一个礼拜,直到三个月后在广交会上跟另外两家同行喝酒,才知道同规格同数量这单市场价普遍在$5.80-6.20——**他每顶少赚$1.3,3,000顶少赚$3,900**,而这笔钱不需要他多干一分钟的活。他的病根写成一句话:**在一个有充分可比价的市场里,他用了一个不看市场的方法。**

两种方法的正确关系,压成一句话记住:

```
成本加成 → 算地板(低于它你不该接)
市场锚定 → 算天花板(高于它客户不会买)
你的报价 → 落在中间,且偏天花板一侧
```

回到9.9,用这个框架体检一次:地板在哪?完全成本¥33.28/顶=6.40加元;按定制服务档40%的最低目标毛利,地板价=6.40÷0.6=**10.67加元**。天花板在哪?本地最低价12加元。**地板10.67,天花板12,而你报了9.9——你报在了地板下面。**这一单能赚钱,靠的是老崔担下¥600返工费、靠的是查验只查了一次、靠的是你没把自己的时间算进去。

本节动作:给你手上每一个产品建一张"锚点卡",三行——①客户现在从哪买、买多少钱(去问,或者去看他的采购页面);②同行报价带(去展会、去平台、去问同行);③我的地板价(完全成本÷(1−最低目标毛利率))。三行齐了再报价。**一行都没有就报的价,不叫报价,叫猜。**

### 19.6.2 安全边际与阶梯设计:留出犯错的空间

上一节把地板和天花板画出来了,这一节讲**中间那段留多宽**,以及怎么把它设计成一张能直接发给客户的阶梯报价单。

先定义。**安全边际(margin of safety)**:你的报价高出保本价的那一部分,通常用百分比表示。保本价不是"成本价"——是**完全成本口径**的成本价,含19.5那七项。用你这单的数:完全成本¥33.28/顶=6.40加元,报价9.9加元,安全边际=(9.9−6.40)÷9.9=**35.4%**(和19.5算出的完全成本毛利率是同一个数,只是换了个说话角度)。

安全边际是干什么用的?它是**犯错的预算**。这一单里,它实实在在被花掉了三笔:

```
折让给 Mike 的 80加元                  = 1.6% 的售价
海关查验杂费 CAD 150(即将发生)         = 3.0% 的售价
两趟山东的差旅 ¥3,500                   = 13.6% 的售价
────────────────────────────────────────────
合计花掉                                = 18.2% 的售价
```

**报价时留出的那几个点,就是事故一那¥416的来处。**如果你当初报的是刚好覆盖账面成本的价格,这80加元的折让你就给不起——你会跟 Mike 争,会想办法让工厂全担,会在一个500顶的小单上把关系搞僵。**安全边际买的不是利润,是你"能爽快认错"的余地**,而在这门生意里,爽快认错是最便宜的客户维护。

给你三条硬线,直接抄进笔记本:

| 档位 | 完全成本口径毛利率下限 | 低于此线的处理 |
|---|---|---|
| 定制服务(你现在这档) | **25%** | 低于25%不接,除非是战略性种子单且写明只做一次 |
| 走量代工/纯贸易 | **8%** | 低于8%必须锁汇+预付款覆盖,否则汇率一动就归零 |
| 现货贴牌/小单快反 | **30%** | 小单固定费用重,低于30%基本是白干 |

25%这条线怎么来的?倒推:七项漏成本合计能吃掉毛利的三分之一(19.5算过),再加上一次中等事故的余量,**你需要至少25%才能保证"出一次事还不亏"**。这不是保守,是这一章所有算例的共同结论。

**现在设计阶梯。**阶梯报价的本质是把19.3那个"一次性费用摊销"的机制**明码标价地交给客户**,让他自己选。用你已经算出的成本,三档:

| 档 | 数量 | 出厂价 | 一次性摊销/顶 | 运费/顶 | 完全成本/顶(¥) | **报价(加元)** | 完全成本口径毛利率 |
|---|---|---|---|---|---|---|---|
| A | 500顶 | 17.5 | 8.80 | 2.80 | 33.51 | **11.5** | 44.0% |
| B | 1,000顶 | 17.0 | 4.40 | 2.78 | 27.69 | **10.5** | 49.3% |
| C | 3,000顶 | 16.6 | 1.47 | 2.78 | 23.62 | **9.5** | 52.2% |

(C档核算:货款¥49,800、洗水¥3,000、制版¥200、寄样¥700、差旅¥3,500、运费2.88方×¥2,900=¥8,352、换汇与折让备付各1.5%×¥148,200=¥2,223、意外备付¥800、资金占用¥66,合计¥70,864;收入¥148,200,毛利¥77,336。)

这张阶梯里藏着四条设计规则,每一条都是可以直接套用的:

**规则一:相邻档的价差控制在8-12%。**11.5→10.5是−8.7%,10.5→9.5是−9.5%。价差太小(<5%),客户没有加量的动力;价差太大(>15%),客户会怀疑你在小单上宰他——**而他的怀疑是对的**,大价差恰恰暴露了你小单报价里的水分。

**规则二:数量越小,毛利率必须越高。**44.0%→49.3%→52.2%,看起来"越大越赚",但这是**结果**不是让步:小单的毛利率低,是因为一次性费用把它压下去了,不是因为你少赚。这条规则的实用价值在于它给了你一句拒绝的话术:"200顶我也能做,但报价会到13.5,因为制版和打样的钱摊不动——**不是我不想给你便宜,是这两笔钱不管做多少顶都一样多。**"

**规则三:检查跳档临界点,让"再加一点"永远划算。**客户订999顶按A档11.5是11,489加元,订1,000顶按B档10.5是10,500加元——**多订1顶,总价反而少989加元。**这个悬崖看起来荒谬,但它是好事:它会把客户从999推到1,000,而你在B档的毛利率反而更高(49.3%>44.0%)。要检查的是反方向:**别让某个档位出现"多订反而你更亏"的区间**。检查方法很简单,把每档的边界数量代进完全成本表算一遍毛利,画在纸上是一条阶梯,每一级的台面都要往上走。

**规则四:阶梯必须带三个附加条款,缺一不可。**

```
① 有效期:本报价有效期 30 天(见9.7.1)
② 汇率:按 1 加元 = ¥5.05 内部结算汇率核定
        汇率波动超过 ±2% 双方重议(见9.7.2)
③ 运价:运费按货代当期报价据实调整,已按现行报价上浮 15% 计入
        (见13.5的buffer规则)
```

第②条要展开讲,因为它是**涨价预留最省事的一种形式**。你的全书算例汇率是1加元≈¥5.2(见0.3),但报价时你应该用一个**内部汇率**(见9.7.2)——比如¥5.05,比市场低3%。这3%不是骗客户,是你的汇率准备金:汇率不动,它是利润;汇率跌了3%,你不用去跟客户重谈。19.7的敏感性分析会告诉你,3%的汇率波动对毛利的杀伤力比20%的运价波动还大,而新人天天盯着运费,对汇率毫不设防。

**最后一条,关于涨价的时机。**新人最怕涨价,总想着"下次再说"。给你一个规则:**涨价永远在客户最满意的时候提,不在成本上涨的时候提。**具体说,就是翻单谈判那一刻——货收到了、活动办成了、Mike 说"帽子大家都很喜欢"的那封邮件之后,你回:"这次我按新的成本结构给你算,棉价和运价都涨了,同样500顶是10.5;如果你能做到1,000顶,还是9.9。"——**把涨价和阶梯捆在一起提,客户听到的不是"你涨价了",是"你给了我一个选择"。**这套话术第24章会在 R&B 翻单时完整用一遍。

本节动作:给你的主力产品做一张三档阶梯报价卡,每档写全"数量/单价/交期/一次性费用是否含"。做完自查两件事:①最低档的完全成本口径毛利率有没有到25%?②三个附加条款写全了没有?**这张卡做好之后,你80%的报价可以在三分钟内完成——而三分钟的报价速度,本身就是一种竞争力。**

## 19.7 Excel模板逐格讲解

前面六节把账算完了。这一节把它变成一个你按一次就出结果的工具——**一张能用三年的到岸成本核算表**,逐格讲。

打开Excel,新建一个工作表,命名"Landed Cost"。整张表分三个区,用底色区分,这是第一条也是最重要的一条设计原则:

```
输入区(浅蓝底)  = 只有这里能手填。别人改你的表,只准改蓝格。

**现在做敏感性分析。**

先定义:**敏感性分析**,就是让表里的某一个输入按一定幅度上下浮动,看结果区的数变化多少;变化大的那个输入,就是这单的"敏感项",是你要重点管理和对冲的地方。

单因素做法最简单:把B5改成5.04(−3%),记下B53;再改成5.36(+3%),记下B53;然后改回来。用 R&B 的账面口径(与7.3.2/13.5可比)跑一遍:

| 变动项 | 幅度 | 毛利(¥) | 毛利率 | 相对基准 |
|---|---|---|---|---|
| 基准 | — | 13,790 | 53.6% | — |
| 汇率 ¥/CAD | −3%(5.04) | 13,032 | 52.2% | **−5.5%** |
| 汇率 ¥/CAD | +3%(5.36) | 14,592 | 55.0% | +5.8% |
| 运价 ¥/方 | +20%(3,480) | 13,514 | 52.6% | **−2.0%** |
| 出厂价 | +5%(¥18.4) | 13,353 | 51.9% | −3.2% |
| 折让 | 售价1.5% | 13,404 | 52.1% | −2.8% |

**结论只有一句,但值一整节:汇率±3%对毛利的杀伤力(±5.5%),比运价±20%(∓2.0%)大得多。**新人天天在微信群里问运费涨没涨,却从来不看汇率——而汇率是唯一一个**你完全无法控制、幅度可以很大、且直接乘在全部收入上**的变量。这就是14.5.2讲锁汇的理由,也是19.6.2要求用内部汇率¥5.05报价的理由。

双因素表,Excel里的做法(这是这张表最专业的一步):

```
1. 在空白区域(比如 E60)填入毛利率公式的引用:=B53
2. E列往下写行变量(运价):2320 / 2900 / 3480
3. 第60行往右写列变量(汇率):5.04 / 5.20 / 5.36
4. 选中 E60:H63 整个矩形
5. 数据 → 预测 → 模拟分析 → 模拟运算表
   输入引用行的单元格:$B$5   输入引用列的单元格:$B$12
6. 确定 → 九个格子自动填满
```

跑出来是这张(毛利率):

| 运价\汇率 | 5.04(−3%) | 5.20(基准) | 5.36(+3%) |
|---|---|---|---|
| ¥2,320(−20%) | 53.4% | 54.7% | 56.0% |
| ¥2,900(基准) | 52.2% | 53.7% | 55.0% |
| ¥3,480(+20%) | 51.1% | 52.6% | 53.9% |

**九个格子,极差4.9个百分点,折¥2,117。**最坏的角落(运价+20%且汇率−3%)仍有51.1%——这就是**安全边际的可视化**:你这单的成本结构厚到足以承受双向的坏消息。

但真正的教学价值在于把同一张表套到别的生意上。拿14.5.1那个走量代工的例子:采购¥100,000、售价¥115,000、毛利15个点。汇率−3%,收入变成¥111,550,毛利掉到¥11,550,**毛利率从15%掉到10.4%**——同样3个点的汇率波动,在54%毛利的单上损失相对值5.5%,在15%毛利的单上损失相对值31%。**同样的风浪,吃水浅的船晃一晃,吃水深的船就进水。**

于是得到本章最后一条规则,请把它写在核算表的表头上:

> **完全成本口径毛利率低于20%的单,必须做以下至少一项:锁汇(见14.5.2)、报价单写入汇率重议条款(见9.7.2)、或要求预付比例覆盖全部采购成本。三样都做不到,这单的风险不由你控制,别接。**

本节动作:今天就把这张表建出来——三个区、三种底色、B54和B56两个公式一个不能少。建完做三件事验收:①用上面那组 R&B 的输入值跑一遍,B50应该出**¥33.24**、B53应该出**35.4%**(对不上说明你哪一格抄错了,这是完全成本口径,和19.5那张表咬得上);②把B19差旅、B22折让备付率、B23意外备付三格清零,B50会变成**¥23.87**、B53变成**53.6%**——**这就是第7章那张账面表**,两个口径的差额在你眼前跳一下,比读十遍19.5都管用;③把B5改成5.04,看毛利掉多少。**第三件事只要做过一次,你这辈子报价都会记得留汇率buffer。**
