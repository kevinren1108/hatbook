# 第2章 帽子解剖:每个零件的名字

拿一顶帽子,从上往下拆。这一章结束后,你要能看懂任何一张帽子规格表,也能听懂工厂的黑话——"6片弯檐,鸡眼,金属扣收尾环"。

## 2.1 帽型总览

### 2.1.1 结构化棒球帽 vs 软顶老爹帽

**结构化(structured)**指帽子前幅内衬了一层硬衬布(布衬),不戴时也能立起来,轮廓挺——经典棒球帽、snapback都是结构化的。**无结构(unstructured)**没有衬布,帽身软塌、贴头型,就是**老爹帽(dad hat)**的慵懒感来源。同一个logo放在两种帽上气质完全不同:结构化=运动/街头,软顶=休闲/文艺。

### 2.1.2 主流帽型速览

| 帽型 | 特征 | 典型人群/场景 |
|---|---|---|
| 经典棒球帽 | 6片、结构化、弯檐 | 最大公约数,球队、品牌 |
| Dad hat | 6片、软顶、弯檐、常配金属扣 | 精品咖啡、潮牌、年轻客群 |
| Snapback | 平檐、结构化、塑料排扣 | 嘻哈街头 |
| Trucker | 前幅泡棉+后半网布 | 户外、蓝领、复古潮流 |
| 高尔夫帽 | 轻薄速干料、常激光打孔 | 运动、企业礼品 |
| 渔夫帽(bucket) | 360度软檐 | 时尚、防晒 |
| 毛线帽(beanie) | 针织、无檐 | 秋冬 |
| 空顶帽(visor) | 只有檐没有顶 | 网球、跑步 |

### 2.1.3 帽型即语言

给客户提案时,帽型选择本身就在传达品牌气质——精酿啤酒厂大概率要dad hat或trucker(手作感),而青少年球队要经典结构化棒球帽(统一感)。这是第22章定制提案的基础。

## 2.2 帽身(Crown)结构

### 2.2.1 帽片(panel):6片与5片

帽身由几片扇形布片拼缝而成,每片叫一个**帽片**。**6片帽**:正前方是两片,一条中缝落在脸的正中线上。**5片帽**:正前方是完整一大片,无中缝。

### 2.2.2 前幅与中缝对logo的影响

**前幅**就是帽子正前方那块区域——logo的家。6片帽的前幅有中缝,绣大logo会跨在缝上(小logo无碍);要绣大图案或贴大面积印花,选5片帽。这是选款时的第一个技术判断。

### 2.2.3 缝份与沿条

布片拼缝处内侧的余量叫**缝份**;帽内盖住缝份的包边条叫**沿条(taping)**——有沿条的帽子内里整洁,是品质档次的信号之一,也是一道额外工缴(第9章工价表里能看到它)。

## 2.3 部件逐个认

### 2.3.1 顶扣(Button)

帽顶正中央那颗包布小圆扣,盖住六片布的交汇点。也有"无顶扣"设计(高尔夫帽常见,避免头盔/耳机压迫)。

### 2.3.2 气眼(Eyelets)

帽片上的透气小孔,两种做法:**绣眼**(线锁边绣出的孔,软,主流)和**金属鸡眼**(金属圈压出,硬,工装感)。

### 2.3.3 帽檐(Brim / Visor)

外层是布,内夹一块**帽檐芯**(通常PE塑料板)定型。分**弯檐**(curved,传统棒球帽)与**平檐**(flat,snapback标配)。檐面上一圈圈的车线叫**檐面线**,行数(常见4-8行)是规格表项目之一——线越多越显工艺。

### 2.3.4 汗带(Sweatband)

帽内圈贴额头的带子,吸汗、定尺寸。棉的舒服、涤的耐用,宽度常见2.5-3cm。

### 2.3.5 四种"标"

- **织唛(woven label)**:织出来的品牌标,质感好,缝在帽内后中或前幅内侧;
- **印唛(printed label)**:印出来的标,便宜;
- **洗水标(care label)**:写成分和洗涤方式——出口件的合规必需品(见18.6);
- **吊牌(hangtag)**:挂在外面的纸牌,零售用。

## 2.4 调节扣(Closure)全家族

帽后调松紧的机关,是选款必答题,每种扣都自带成本档位和风格暗示:

| 扣型 | 描述 | 成本 | 风格暗示 |
|---|---|---|---|
| 塑料排扣(snapback扣) | 一排凸点按进孔,"啪啪"扣上 | 最低 | 街头、嘻哈 |
| 魔术贴(velcro) | 一撕一贴 | 低 | 休闲;用久粘性衰减、显廉价 |
| 织带日字扣 | 布织带穿"日"字扣 | 中 | 中性、运动 |
| 金属滑扣+收尾环 | 布带穿金属扣滑动,尾端金属环收口 | 最高 | 精品dad hat标配,质感担当 |
| 全封弹力(fitted/flex) | 无开口,弹性面料分码 | 高(管理成本) | 正版球队帽、专业运动 |

**全封分码逻辑**:没有调节扣就必须按头围出尺码(S/M、L/XL),工厂要多套版、你要压多码库存——所以定制小单几乎不做fitted,这是成本常识而非工厂偷懒。

## 2.5 尺寸语言

### 2.5.1 三个核心尺寸

- **帽围**:帽口一圈的周长,成人可调款通常覆盖56-60cm;
- **帽深**:帽口到帽顶的高度,决定"戴得深不深"(dad hat浅、棒球帽标准、嘻哈款深);
- **檐长**:帽檐前伸长度,常见7-7.5cm。

### 2.5.2 码段

成人均码(可调)/ 青年码(54-57cm)/ 儿童码(50-54cm)。做球队单会同时遇到成人和青少年,报价和排产都要分开算。

### 2.5.3 规格表(Spec sheet)

把帽型、片数、面辅料、三围尺寸、工艺、标类、包装全部写成一张表,就是规格表——它是打样需求(第10章)、报价锁定(第9章)、验货依据(第11章)共用的同一份文件。**外贸的一切纠纷,最后都回到规格表写没写清。**
