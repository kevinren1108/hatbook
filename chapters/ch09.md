# 第9章 看懂报价单:一顶帽子的钱都花在哪了

## 9.1 从一个数字到一张拆分表

你向工厂询价:"6片棉斜纹棒球帽,前幅平绣logo约9000针,金属调节扣,5000顶,FOB上海。"几天后收到报价:**FOB USD $1.95/pc**。

一个数字,什么信息都没有。新手到这里就开始砍价:"能不能1.8?"——这是最外行的谈法:你不知道1.95里面是什么,砍下来的每一分钱,工厂都能从你看不见的地方拿回来。老手的做法是要**成本拆分(cost breakdown)**。一张诚实的拆分单大致长这样(人民币计价):

| 项目 | 明细 | 单顶成本 |
|---|---|---|
| 帽身面料 | 全棉斜纹,约0.16㎡/顶 | ¥3.20 |
| 帽檐芯 | PE塑板 | ¥0.45 |
| 汗带 | 涤纶汗带 | ¥0.35 |
| 织唛+尺码标 | 主标织唛 | ¥0.20 |
| 调节扣 | 金属滑扣+鸡眼扣 | ¥0.60 |
| 绣花 | 9000针×¥0.45/千针 | ¥4.05 |
| 裁剪工缴 | | ¥0.30 |
| 车缝工缴 | | ¥3.00 |
| 后整+包装 | 定型、剪线、单塑袋、外箱分摊 | ¥0.70 |
| 损耗 | 按小计3% | ¥0.38 |
| **生产成本小计** | | **¥13.23** |
| 管理费+利润 | 约18% | ¥2.38 |
| 内陆运输+报关杂费 | | ¥0.35 |
| **FOB成本合计** | | **¥13.96 ≈ $1.95**(汇率7.15) |

要拆分的话术:"我们内部做预算需要cost breakdown,方便后续翻单时按项调整。"——给工厂一个"给你拆分对它有好处"的理由(翻单预期),比硬要有效得多。

## 9.2 面料成本:反算法与换料猫腻

面料占一顶帽子成本的20-30%,由**材质、克重、用量**决定(术语见1.1-1.3)。

**反算公式**:合理面料成本 ≈ 克重对应的米价 ÷ 门幅 × 单顶用量(0.15-0.18㎡)。面料市价¥18/米、门幅1.5米(即¥12/㎡),单顶合理区间¥1.8-2.5;报¥3.2,要么面料真高档,要么塞了利润——可以问。

**换料猫腻**:你砍价成功后,工厂换轻克重面料或改混纺比,肉眼看不出,成本悄悄降五毛。防法:报价时写死"全棉斜纹,克重240±5%",封样时剪面料小样留底,大货对照(封样制度见10.6)。

## 9.3 辅料成本:档次替换

金属滑扣¥0.5-0.8,换塑料扣只要¥0.15;织唛分高密度与普通密度。辅料谈判的价值不在砍价,而在**明确规格防替换**——PI附一页辅料清单(trim sheet):调节扣材质、织唛工艺、汗带宽度,并照片确认。"大货和样品不一样"的投诉,出事的多半是辅料。

## 9.4 绣花成本:针数验证三招

绣花按针数计价(¥0.35-0.55/千针,原理见3.1.5),而**针数是工厂说了算,是整张报价单水分最大的地方**——同一logo报9000针还是12000针,单顶差¥1.35,五千顶就是近七千块。三招验证:

1. **要针数明细**:打带软件直接生成,截图就有;
2. **两家对比**:同一logo问两家厂,针数差超15%就有问题;
3. **自查文件**:要`.dst`文件,用免费查看器自己看针数(见3.1.9)。

另防两笔:**制版费**首单收、翻单不该再收;帽后加绣小logo是另一套针数,报价别漏算。

## 9.5 工缴:为什么砍工缴没有意义

裁剪¥0.2-0.4、车缝¥2.5-4、后整包装¥0.5-1——付给工人的计件工资加车间分摊,由帽型复杂度决定(6片比5片多两道拼缝;夹沿条、绣眼都加钱)。工缴基本是行业公价,**工厂真让步了,代价是你的单被排到最不熟练的新工人线上**。新手对着总价瞎砍,压掉的全是做工质量。

## 9.6 弹性项:真正的谈判空间

- **损耗率**:2-3%正常,报5%就是藏利润;
- **管理费+利润**:行业15-25%,大单、简单款取低,小单、打样多、要验厂取高。

这两个比例项才是谈判空间。但注意:工厂拆分给不给、诚不诚实,取决于你的订单吸引力和**专业度**——你能逐项验算,工厂就不敢乱报;你只会喊"便宜点",拆分单做给你看也是表演。

## 9.7 报价单外的五个价格变量

1. **数量阶梯**:5000顶和500顶单价差25-40%(面料起订量、开机效率、制版费摊薄)。**询价必须带数量**,拿大单报价做小单预算必死;
2. **汇率buffer**:工厂按低于即期1-2%的内部汇率折算美金价,给自己留波动垫。美金报价突然涨,不一定是成本涨,可能是财务调了内部汇率;
3. **付款方式**:100%前TT可换1-2%价格优惠;要账期则加价(付款方式详见第14章);
4. **淡旺季**:帽厂旺季3-9月(赶欧美秋冬和圣诞订单),议价难交期长;11月-次年2月淡季,同一张单便宜5-8%、交期腰斩。**翻单备货尽量排淡季**;
5. **退税已在价里**:帽子出口退税约13%,工厂报FOB价时退税收益已计入利润模型(原理见18.3)——出口价"反常便宜"是正常的,别以为工厂亏本。

## 9.8 询价SOP

1. **锁规格**:材质克重、辅料清单、针数上限、包装、数量、术语、付款,写成一页规格书;
2. **三家询价**:产业带不同的厂各一家(产业带见第6章);
3. **要拆分,逐项验算**:面料反算、针数核对、损耗率;
4. **问why不问"能不能便宜"**:"你们绣花报12000针,另一家9000,差在哪?"——让工厂知道你懂行,水分自动挤出;
5. **入PI**:最终规格+拆分价写进PI附件,作为大货验收依据。

---

> **本章作业**:把一个logo发给1688上三家定制帽厂询价,数量分别报200和2000,要求提供针数。把六份报价填进对比表,亲手找出不一致——本章讲的每个猫腻,几乎都能在真实报价里抓到现行。
